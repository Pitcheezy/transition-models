## 1. 목적과 오류 복구

“저희 파트는 구종 추천에 필요한 투구 결과 확률을 추정합니다.
좋은 확률 모델이 실제 추천에도 도움이 되는지 확인하는 것이 목표입니다.
기존 77차원 입력과 정답의 순서가 달라 투구 ID로 다시 연결했습니다.
복구한 77차원 MLP는 세 시드 모두 약 67.6% 정확도를 보였습니다.
따라서 과거 41%에서 67%로 오른 이유를 맥락 추가라고 설명할 수 없습니다.
이 정확도는 실제 투구가 끝난 뒤 관측되는 특징도 포함한 분류 성능입니다.”

## 2. 투구 전 정보만 사용하는 평가

“추천 시점에는 실제 도착 위치와 구속을 알 수 없습니다.
2022년 이력으로 투수별 구종 프로필을 만들고 고정했습니다.
2023년에 학습하고, 2024년 1~5월로 모델을 선택하고, 6월로 확률을 보정했습니다.
마지막 7~9월 약 34만 투구는 최종 평가에만 썼습니다.
학습 데이터와 실제 추론은 같은 특징 생성기를 사용합니다.”

## 3. 확률 성능과 희소 사건

“검증 CE로 선택된 모델은 135차원 MLP 세 시드 앙상블입니다.
최종 CE는 경험적 확률표 1.2874에서 1.2743으로 개선됐습니다.
Brier도 0.6595에서 0.6568로 낮아졌습니다.
77차원에 대한 일반적 우월성까지 확인한 것은 아닙니다.
운영 정확도는 약 45.5%이며, 이전의 67%를 추천 정확도로 홍보하지 않습니다.”

“홈런을 최대 확률 클래스로 고른 횟수는 0이지만 평균 홈런 확률은 0.825%,
실제 빈도는 0.808%였습니다. argmax recall과 사건 확률을 구분해야 합니다.
상황별 편향도 남아 전체 평균만으로 완벽한 보정을 주장하지 않습니다.”

## 4. 정책 효용 결과

“경험적 확률표와 학습 모델에 동일한 구종 후보와 실점 비용 계산을 적용했습니다.
약 19만 5천 적격 투구에서 추천 구종은 63.1% 달라졌습니다.
별도 실제 경기 결과를 이용한 평가에서 학습 정책의 비용 차이는 100회 결정당
−0.086점이었고 95% 신뢰구간은 −0.405~+0.230점이었습니다.
0을 포함하므로 실점 개선을 입증하지 못했습니다.
확률 예측의 개선과 정책의 개선은 서로 다른 검증 문제라는 결과입니다.”

“이 평가는 관측자료에 가정을 둔 한 번의 구종 선택 평가입니다.
전체 시즌 절감이나 무작위 실험의 인과효과를 확인한 것은 아닙니다.”
