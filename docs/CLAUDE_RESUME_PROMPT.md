우선 새 검사 세션으로 전체 프로젝트를 반복 감사하지 말고 **3번 타석부터 연속 한 타석**을

8772가 이미 사용 중이면 해당 서비스인지 확인하고 재사용하거나 다른 로컬 포트를 선택해라.

영상 재생에는 인터넷과 실제 장면을 볼 수 있는 도구가 필요하다.

Chrome에서 실제 영상 장면을 보고 판단 시각·릴리스 시각·오차 범위·확인 근거를 추가해라.
Git에 저장된 주석을 먼저 불러와 보존하고 새 항목만 추가해라. 저장·내보내기 후 CLI를
다시 실행해 검증 보고서를 갱신해라. 확인 불가나 미검토 항목을 완료로 세지 마라.

현재 도구로 영상을 직접 볼 수 없다면 추정 시각을 만들지 마라. 필요한 접근 방법을
정확히 기록하고, 이미 검증된 주석을 사용하는 **점수판 인식 평가셋의 ID·라벨·가림 상태·
오차 집계 규약 및 검증 코드**를 다음 독립 작업으로 진행해라. 기록 메타데이터를 OCR이
읽은 결과처럼 넣지 마라. 실제 장면 확인이 필요한 입력은 미확인으로 남겨라.
