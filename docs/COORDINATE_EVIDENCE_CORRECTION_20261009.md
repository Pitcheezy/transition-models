## 새 출력의 의미

기존 좌표·행렬·변환 방식/버전을 유지하고, 변환 근거에 실제 적용한 명목 보정값과
남아 있는 깊이 가정의 민감도를 나누어 기록한다.

- 적용 보정량: x는 `−명목 깊이 × pan_tan`, z는 `−명목 깊이 × tan(tilt)`이며 단위는 피트다.
- 잔여 민감도: 실제 깊이와 명목 깊이의 차이가1피트일 때, 이 변환 모델에서 추정값−참값에
  더해지는 x/z 변화는 각각 `pan_tan`, `tan(tilt)`다. 단위는 ft/ft다.
- 깊이를 측정하거나 새 보정 정확도를 검증한 결과가 아니다. 실제 깊이 차이를 모르면 잔여 오차의
  크기도 확정하지 않는다. 보정 없음 또는0값은 근거에 그대로 나타낸다.

기존 미트 x가 바뀌거나 서비스가 높이를 새로 표시하는 변경은 없다. 기존 JSONL·M3·
사람 응답·배포 파일과 전달 ZIP은 고정한다. 새 코드를 사용해 이후 출력하는 근거만 바뀐다.
기존 결과를 다시 생성해 성능 개선이나 물리 정확도 향상으로 제시하지 않는다.

## 검증

합성 부호/영보정/미보정 검사와 저장된5경기 자료로 수정 전후를 비교했다.
좌표·상태·기권·오차·집계는 같아야 하며, 변환 근거의 정정 대상 필드만 달라질 수 있다.
기존 원자료26파일 SHA도 대조했다. 실제 수와 실행 결과는
[검증 기록](results/cv_independent_20261009/coordinate_evidence_v1.json)에 고정한다.
이번 작업은 새 영상 판독·학습·새 사람 평가가 아니다. 팀원 레포/API와 공개 사이트는 수정하지 않았다.

수정 소스는 우리 `feature/intent-v0`에 있다. 기존 최소 소스 ZIP v2는 `bf1fb5d`의 고정본이므로
이 정정이 포함되지 않는다. 최신 코드가 필요한 통합에서는 커밋을 확인해 전체 저장소를 사용한다.
