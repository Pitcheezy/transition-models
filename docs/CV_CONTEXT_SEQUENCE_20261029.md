원본과 기존 고정크롭은 같은 이미지의 두 보기다. 이전 AI 상자 없이 원본 문맥을 먼저 읽는다.

- 미트 모양만으로 채택하지 않는다. 포수의 팔→손목→후보 연결이 보이는지 별도 기록한다.
- 다리/몸통에 부착된 장비와 손에 든 물체를 구분한다. 가깝거나 비슷한 색은 부착 증거가 아니다.
- 팔/손목이 가려지면 `occluded`, 소유자가 불분명하면 `unclear`; 연결을 추정으로 채우지 않는다.
- 화면 좌우만 사용한다. 확인 못 한 신체 좌우를 단정하지 않는다.
- 간격 표본 사이 움직임·가림 없는 동일 객체 추적은 미측정이다.
- Codex 응답을 먼저 저장하고 Claude Fable이 같은15장을 읽는다. 불일치를 보존하며 다수결을 하지 않는다.
- `catcher + visible + mitt_like + wrist + box`는 각 AI의 **개발 근거 형식 충족**일 뿐 검증된 미트가 아니다.
  두 AI가 충족해도 새 미트 중심·의도·제구오차·사람 대비 정확도를 산출하지 않는다.
- 마지막 표본 이후에야 사용할 수 있는 사후 근거다. 대표 프레임보다 뒤의 근거를 당시 가용 판독으로 쓰지 않는다.
  릴리스 경계는 기존 AI 구간 메타데이터이며 정밀 릴리스 실측이 아니다.
