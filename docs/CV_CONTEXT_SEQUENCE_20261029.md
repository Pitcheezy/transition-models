# CV49c — 팔·손목·장비 관계와 시간순 표본

## 판독 전 고정 규칙

기준 `ede316b0015886e986f4260cdfc74f083876ec58`, 초안 PR84. 개발 경기849843 첫 타석3구만 사용한다.
기존80프레임 구간에서 각 첫장·대표 앞 중간·대표·대표 뒤 중간·마지막장, 중간 인덱스는 내림한다.
목록은 [고정 계획](results/exhibition_replay_20261028/context_sequence_plan_v1.json)이다.
각5장·총15장, 0.4015/0.4004/0.5005초 간격 표본이며 **연속 추적이나 새 평가 표본이 아니다**.
원본과 기존 고정크롭은 같은 이미지의 두 보기다. 이전 AI 상자 없이 원본 문맥을 먼저 읽는다.

- 미트 모양만으로 채택하지 않는다. 포수의 팔→손목→후보 연결이 보이는지 별도 기록한다.
- 다리/몸통에 부착된 장비와 손에 든 물체를 구분한다. 가깝거나 비슷한 색은 부착 증거가 아니다.
- 팔/손목이 가려지면 `occluded`, 소유자가 불분명하면 `unclear`; 연결을 추정으로 채우지 않는다.
- 화면 좌우만 사용한다. 확인 못 한 신체 좌우를 단정하지 않는다.
- 간격 표본 사이 움직임·가림 없는 동일 객체 추적은 미측정이다.
- Codex 응답을 먼저 저장하고 Claude Fable이 같은15장을 읽는다. 불일치를 보존하며 다수결을 하지 않는다.
- `catcher + visible + mitt_like + wrist + box`는 각 AI의 **개발 근거 형식 충족**일 뿐 검증된 미트가 아니다.
  두 AI가 충족해도 새 미트 중심·의도·제구오차·사람 대비 정확도를 산출하지 않는다.
- 마지막 표본 이후에야 사용할 수 있는 사후 근거다. 대표 프레임보다 뒤의 근거를 당시 가용 판독으로 쓰지 않는다.
  릴리스 경계는 기존 AI 구간 메타데이터이며 정밀 릴리스 실측이 아니다.

## 사용자 화면의 목적

CV49a/b의3장 화면은 같은 입력에서 AI와 기존 검출기가 어디를 지목하는지 비교한 진단이다.
사용자에게 정답 입력을 요구하거나 전시 완성품을 대신하지 않는다. CV49c는 같은 개발 흐름에
5장 순서·현재 프레임 관계·기권 이유를 더한다. 현재 프레임의 상자만 보며 과거 상자를 옮겨 그리지 않는다.
두 AI 일치는 정확도가 아니다. 불분명하면 판단을 보류한 상태가 올바른 출력이다.

  기존v3의 후보/2구 기권도 자동 변경하지 않았다. 앞으로의 후보 선택에 필요한 관계 근거를 명시했지만
  운영 자동검출기의 성능이 개선되었다고 보고하지 않는다.

### 판독의 형식 오류와 한계

Claude 최초3응답은 `image_sha256`에 실제 해시 대신 `unchanged`를 써 수용할 수 없었다.
원문을 보존하고, 새 이미지 읽기 없이 고정 PTS→해시15매핑을 한 번 보완 확인한 뒤 결합했다.
2구 설명의 약9ms 간격도 실제9009tick/90000=100.1ms로 정정했다. 상자·물체 판단은 재투표하지 않았다.
이 텍스트 보완은 새로운 독립 판독이 아니다. 초기 Codex 기록의 미확인 세부 모델명은 원문을 보존하고
별도 메타데이터 사본에서 `Codex (runtime model ID unavailable)`로 바로잡았다. 판독 내용은 동일하다.
AI 원문 안의 장비/신체/광고물 해석은 미검증 관측이다. 사람이 확인한 사실로 인용하지 않는다.

### 구현·검증

`82_build_context_sequence.py`는 기존 v1 객체 형식을 바꾸지 않고 `(pitch_key, PTS)`로15장을 결합한다.
manifest/판독 SHA, 실제 프레임 PTS·이미지 SHA·키, 중복/순서/릴리스 이전 조건·정수 상자를 검사한다.
마지막 참고 PTS를 명시해 대표 이후 프레임을 당시의 온라인 분석으로 쓰지 않는다.
검토 지적에 따라 **원본을 고정 영역으로 자른 픽셀과 확대 파일을 대조**한다. 해시가 맞아도 다른 프레임의
크롭이나1픽셀 어긋난 크롭은 거부한다. RGB/RGBA만 허용하며 리사이즈하지 않는다. 기존 Pillow 환경을 사용한다.
출력은 새 비공개 폴더만 허용한다. 저장 도중 디스크 오류가 나면 부분 산출물을 지우거나 성공 처리하지 않는다.

- 최종 관련 Python **189 passed /27.42초**, Ruff **192경로 통과**. 전체 pytest 재실행은 하지 않았다.
- Windows Chrome155에서15장 탐색,3구 전환 초기화, 이전/끝 이동, 원본/크롭30SHA,
  마지막 불명 후보의 상자 숨김, 좁은 화면 overflow 없음, 외부요청0·페이지오류0 확인.
  좁은 창 검사는 실제 휴대폰/Mac 검사가 아니다. 캡처5개는 비공개 보존한다.
- 원본audit/context 결속15건·원본/크롭30SHA·픽셀일치15쌍·기존재생팩4SHA 불변 확인.
- Claude 고정 코드 검토와 지적별 처리는 [영수증](results/exhibition_replay_20261028/context_sequence_v1.json)에 기록한다.
