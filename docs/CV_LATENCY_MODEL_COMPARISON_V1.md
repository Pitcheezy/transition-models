# CV 구간별 처리 시간·모델 비교 — 2026-10-06

CV-11은 같은 개발 영상의 기존 10시각을 Opus, Haiku 순서로 한 번씩 실행한다.
양쪽 모두 구조화 출력과 동일한 검증기를 사용한다. 모델명만 바꾸며 기존 CV-9/10은 보존한다.
[호출 전 고정 규약](results/cv_followup_20261006/latency_model_comparison_preregister_v1.json)에
시각·예상 이미지 해시·코드 해시·실패 처리·집계 항목을 기록했다. 이 커밋 시점에는 호출 전이다.

프레임 추출, 요청 준비, 외부 관측 프로세스, 결과 검증을 서로 겹치지 않는 구간으로 기록한다.
관측 프로세스 안의 인증·CLI·응답 처리는 별도 중첩 구간이다. 둘을 더해 총 시간으로 쓰지 않는다.
CLI 시간에는 네트워크·서버 대기·생성·내부 구조화 처리 등이 포함되며 순수 모델 추론 시간이 아니다.
이전 데이터에 없는 계측은 0으로 채우지 않는다. 외부 종료 시각이 없는 중단은 오류 분모와
메타데이터 해시를 보존하고 해당 provider 구간을 집계하지 않는다.

명시한 모델과 초기화·assistant 주 모델명을 확인한다. 보조 modelUsage 항목은 대체 근거가 아니다.
모델이 바뀌거나 확인할 수 없으면 응답을 거절한다. API 전환·재호출·표본 교체는 하지 않는다.

실행은 로컬의 `outputs/cv_latency_compare_v1/preregister/{opus,haiku}.json`을 사용한다.
`python -m intent.observation_loop --plan PLAN --out NEW_DIRECTORY`로 실행하고,
`python -m intent.observation_report --run-dir RUN --out NEW_JSON`으로 보존 결과를 검증한다.
이미지·기기별 경로·제공자 원문은 Git 제외다. 공개 보고서는 해시와 집계만 담는다.

한 번씩 순서대로 실행하는 소규모 개발 비교이므로 서버·네트워크·캐시·시간대 효과를 분리하지 못한다.
수락은 위치 정확도가 아니며 두 모델의 일치도도 정답률이 아니다. 독립 사람 라벨, 새 영상 평가,
CV-5a4 전체 타석 확인, 실시간 중계 검증은 별도 미완료로 남긴다.
