# 기존 사람 점 기반 조건부 위치 회귀 — CV-15

범용 글러브 탐지기의 개발 결과가 부족했으므로 기존 84개 사람 점을 직접 사용하는 작은 위치
회귀 후보를 준비했다. **이미 미트 점이 표시된 프레임과 수동 camera crop을 전제로 한 개발 실험**이다.
미트 탐지·부재 판단·포수 역할·새 관측 규약의 정확도로 설명하지 않는다.

823407의 28점으로 학습해 849845의 56점을 평가하고, 반대 방향도 수행한다.
각 방향 seed 42/43/44, 20epoch, batch 8, AdamW lr 0.001 / weight decay 0.0001을 고정한다.
6개 최종 체크포인트를 먼저 모두 저장·해시 고정한 다음 평가한다. 평가 경기 결과로 모델·epoch·
ROI·정규화를 고르지 않는다. 고정 crop 중심과 **학습 경기에서만** 계산한 평균 점을 함께 비교한다.

RGB crop을 192×128로 변환하고 14,369 parameter TinyCNN으로 48×32 heatmap을 만든다.
고정 Gaussian 표적의 cross entropy로 학습하고 공간 softmax의 좌표 기댓값을 출력한다.
Gaussian 폭 1.5칸은 학습 설정이며 실제 미트 크기·라벨 불확실성·확률 보정 결과가 아니다.
CPU 4 threads를 고정하며, 총 학습 update는 660회다. augmentation·조기 종료·최고 seed 선택은 없다.

옛 사람 기권 2장은 음성으로 쓰지 않는다. 실제 비교 분모는 기존 표시 84장이고, 오류/미출력도
그 분모에 남긴다. seed 반복 252개 예측을 서로 독립인 252장이라고 하지 않는다.
두 경기 모두 이미 본 개발 자료다. 경기별 학습 분리와 새로운 독립 검증은 다른 개념이다.

다음 개발 후보로 계속 검토하는 기준도 호출 전에 고정한다: 여섯 조건 모두 오류/미출력 없이,
원본 픽셀 거리의 median과 p90이 두 기준선보다 모두 낮을 때만 후보로 남긴다.
이 기준을 통과하더라도 운영 채택이나 정확도 입증은 아니다. 새 사람/미열람 검증은 별도로 필요하다.

[호출 전 규약](results/cv_local_20261007/point_preregister_v2.json).
학습 자료 원본·참조 정합은 [CV-12 입력 감사](results/cv_local_20261007/dataset_audit_v1.json)를 사용한다.

```bash
python -m intent.local_point_experiment --plan PLAN.json --out outputs/cv_local_point_run_NEW
```

새 출력 디렉터리에 plan/run manifest, training6, checkpoint6, 고정 ledger, evaluation6,
순서 events와 report가 남는다. report의 상대 파일 경로·해시로 저장 결과를 연결한다.
원본 이미지와 체크포인트는 Git 제외다. 전체 서비스 시간이나 새 실시간 성능은 이 실험에서 재지 않는다.

유지보수: 새 CV 결과 JSON도 Git 줄바꿈 변환을 끄고 실행 당시 원본 바이트를 보존한다.
이전에 커밋된 6개 JSON은 내용 변경 없이 CRLF 원본을 복원했다. 기기별 실행 계획의 절대 경로와
코드 바이트 해시는 해당 실행 환경에 묶여 있으며, 다른 기기에서 결과를 덮어쓰거나 해시를 재작성하지 않는다.

실제 학습 전 읽기 전용 감사에서 출력 JSON 해시를 마지막에 새로 채택하는 결함을 발견했다.
기록 시점 해시 고정·종료 시 재검증과 변조 회귀 검사를 추가한 v2 규약으로 대체했다.
v1은 실행하지 않았으며 보존한다. 학습·평가 조건은 동일하고 실제 데이터 학습 호출은 이 시점 0회다.
