# CV-39b — 저장 프레임과 이름 OCR 관측 연결

## 착수 전에 고정한 합격 기준

2026-10-26 사용자 요청의 독립 CV 후속이다. CV39a 팩의 첫 투구 `747139:3:1` 전체74장에 기존 `SNYPlayerNameReader(CONFIG_V2)`만 적용한다. 새 영상·외부 API·사람 라벨·명단·정답 이름을 입력하지 않으며 기존 v1~v4 OCR과 F-4i 독립 평가 상태는 바꾸지 않는다. 연구 브랜치에서 CV39a와 다른 파일로 구현한다.

- 영수증 SHA를 외부 인자로 고정하고 payload와 선택된 투구 모든 이미지의 SHA/크기/해상도·시간순 키를 검사한다. 현재 프레임팩의 manifest 기반 시각 한계를 그대로 보존한다. 기존 밀리초 영수증을 꾸며 만들지 않는다.
- 프레임마다 투구 키/원본 번호/시각/이미지 SHA, 판독 원문/정규화 이름/기권·엔진 오류 이유, 실제 엔진·설정·소스 해시를 기록한다. 이름이 없거나 실패해도 분모에서 제외하지 않는다.
- 같은 투구·역할의 바로 앞 유효 판독과 문자열 일치/변화만 비교한다. 시간 간격0.25초 초과, 기권/오류, 투구 변경에서 비교를 초기화한다. 이전 이름을 현재에 채우거나 선수 ID·교체·`continuity=confirmed`·정확도·동일 선수로 승격하지 않는다. 미래를 읽어 과거 결과를 변경하지 않는다.
- 모든 입력 검증이 끝난 뒤만 OCR을 호출하고 새 출력 폴더만 쓴다. 원본 불변, 변조/경로 이탈/다른 투구/중복·역순 거부, 접두 불변과 역할별 초기화 검사를 수행한다.
- 실제 로컬 Windows OCR 실행 결과와 실패를 분리하고, 작성자와 다른 실제 Claude 고정 소스 검토를 받는다. 새 모델 설치·환경 전역 변경·팀원 코드/프로세스·배포·공개 계약·옛 질문 발신은 없다.
