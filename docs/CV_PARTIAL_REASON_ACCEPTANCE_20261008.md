# CV-28 AI 부분 가림 응답의 사유 검사 — 2026-10-08

새 AI 응답이 `marked/partial`이면 부분 가림을 설명하는 비어 있지 않은 `reason`을
요구한다. 기존 관측 규약의 사유 요구를 요청 문구와 실제 수신 검사에 맞췄다.
빈 문자열이나 공백만 있는 사유는 응답 발행·세션 수락 전에 거부한다.
`marked/full`의 빈 사유와 기존 기권 규칙은 유지한다.

새 스키마 필드나 모델·서비스 계약은 추가하지 않았다. 새 요청에는 명시된 사유 지시를
담고, 기존 요청·세션·코드 SHA 결속을 유지한다. 이전 코드로 시작한 세션을 새 코드에서
끝낼 수 없다는 기존 정책도 유지하므로 새 요청은 새 세션에서 시작한다.

## 저장된 결과의 호환성

새 응답 검사와 보존 결과 판독을 구별한다. 보고서는 저장된 `prompt`와 `response_schema`의
정확한 쌍으로 당시 규칙을 선택한다. 옛 쌍의 빈 partial 사유는 원문대로 읽고, 새 쌍의
빈 partial 사유는 거부한다. 옛 문구와 새 설명을 섞은 쌍도 거부한다.
그 결과를 새 규약 통과나 사유 보완으로 표시하지 않으며 과거 응답·판정을 수정하지 않는다.

접근 가능한 기존 결과139개 중 `marked/partial`은17개였고, 그중5개는 사유가 비어 있었다.
동일 입력을 메모리에서 변경 전후 비교하여 결과·요청278파일의 바이트 불변,
일반 관측 보고서15개와 로컬 검출기 보고서1개의 전체 내용 불변을 확인했다.
접근할 수 없는 테스트 출력 디렉터리25개가 있어 모든 로컬 파일의 전수 검사라고 주장하지 않는다.

## 확인 범위

- 새 partial 응답의 빈 사유·공백 사유를 세션과 일반/구조화 제공자 응답에서 거부한다.
- 사유가 있는 partial과 빈 사유의 full은 허용한다.
- 저장된 옛/새 요청의 규칙 선택과 혼합 쌍 거부를 검사한다.
- 준비된 변경의 관련 합성 검사279개와 정본 관련9파일314개가 통과했다. Ruff161경로·독립 호출경로 검토도 통과했다. 실제 모델 호출·재학습·영상 재판독은 없다.

이는 입력 계약 수정이다. 관측 정확도, 사람 간 일치도, 목표 위치나 투수 의도를 검증한 결과가 아니다.
기존 M3·사람 응답·공개 Site와 팀원 서비스는 변경하지 않는다.
