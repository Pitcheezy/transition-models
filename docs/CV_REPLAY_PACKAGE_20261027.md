# CV44 — 검사 후 실행하는 비공개 CV 재생팩

## 범위와 합격 기준

[착수·기준](https://github.com/Pitcheezy/transition-models/issues/3#issuecomment-6424041496), 기준PR79 `073ca21`, 브랜치 `codex/cv-replay-kit-1027`. 이전 CV41a 일회 포장을 재사용 가능한 검사·빌드·실행 코드로 바꾼다. 기존팩은 보존한다.

CV43 v3의630파일과 영수증을 viewer/에 담고, 루트에 실행기·기존 표준라이브러리서버·README·manifest를 넣는다. 모델/PyTorch/Pillow/OCR을 다시 실행하거나 설치하지 않는다. 고정 영수증SHA·정확한 파일목록·크기·SHA·안전한 상대경로를 검사한 뒤, 메모리에 검증한 UI파일만 loopback으로 제공한다. 원본·사람응답·운영설정·비밀·외부주소를 새로 넣지 않는다.

받은 ZIP의 외부SHA핀과 CRC·전체목록·대소문자충돌·중복·경로이탈·링크를 검사한 뒤 새폴더에만 압축해제한다. 기존출력은 덮어쓰지 않는다. 동봉manifest와 해시는 출처의 암호학적 인증이 아니다. 비공개경로로 받은 외부ZIP SHA가 신뢰기준이다. helper는 무결성검사 뒤에만 불러온다.
