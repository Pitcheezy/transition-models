# 새 관측 규약의 사람 점 자료 준비 v1

2026-10-08. CV6에서 반환된 사람 응답을 원본 프레임에 연결해 보존하는 준비 도구다.
기존 검토 검사·집계를 재사용하고, 이후 학습에서 사용할 수 있는 점과 결측 상태를 분리한다.
학습·모델 호출·자동 합의는 수행하지 않는다.

현재 실제 새 사람 응답은 **0개**, 새 규약의 점 주석은 **0개**, 전원 미검토는 **26장**이다.
실제 CLI 실행에서 기존 CV12 원본 **86장**과 CV6 재검토 **26장**의 연결을 확인하고,
`outputs/cv_review_point_data_20261008_v1/`에 대기 상태를 저장했다.
[공유용 집계](results/cv_independent_20261008/review_point_summary_v1.json)에는 경로·개별 좌표·검토자 ID가 없다.
CV6 26장은 과거 사람 표시 84장의 부분집합이다. 새 이미지 26장이 추가되거나,
84장과 합쳐 110개의 서로 다른 학습 이미지가 된 것이 아니다. 과거 84점과 2기권은 보존한다.

## 입력과 실행

저장소 루트의 기존 Python 환경에서 실행한다. 출력은 `outputs/` 안의 새 디렉터리여야 한다.
기존 디렉터리는 덮어쓰지 않는다. 아래 `NEW`는 아직 존재하지 않는 이름으로 바꾼다.

```text
python -m intent.review_point_data --package outputs/cv_review_20261005_ui_v1 --dataset-manifest outputs/cv_local_dataset_v1/manifest.json --dataset-audit docs/results/cv_local_20261007/dataset_audit_v1.json --out outputs/cv_review_point_data_NEW
```

응답 없는 실행은 대기 상태를 기록한다. 실제 사람이 내보낸 응답을 받으면 같은 명령에
`--response path/to/reviewer_a.json`을 추가하고 새 출력 이름을 쓴다.
다른 사람의 응답도 함께 보존하려면 `--response path/to/reviewer_b.json`을 반복한다.
빈 양식, 중복 제출, 동일 검토자 ID의 중복 응답은 실제 응답으로 받지 않는다.

검토자는 [기존 입력 화면](CV_REVIEW_UI_V1.md)의 **JSON 내보내기**로 별도 파일을 저장한다.
허용 응답은 `intent_source_review_response_v1`, 규약은 `cv_observation_v1`이다.
비슷한 필드를 가진 `intent_visual_observation_v1`은 AI 관측 계약이므로 사람 라벨 입력으로 거절한다.

원본은 `docs/results/mlb_p0/`의 기존 CV12 자료와 manifest가 가리키는 로컬 JPEG를 사용한다.
원본 영상·이미지를 다운로드하거나 다시 추출하지 않는다. 다른 기기로 옮길 때는 기존 CV12의
절대 경로 결속까지 맞아야 하며, 경로나 해시를 임의로 고쳐 검사를 통과시키지 않는다.

## 두 출력 파일

| 파일 | 내용과 보관 범위 |
|---|---|
| `manifest.json` | 비공개 로컬 자료. 원본 이미지 경로·SHA·크기·프레임 시각, 투구/경기 키, 검토자별 원응답 필드·응답 SHA, 소비한 입력 경로·SHA를 보존한다. |
| `summary.json` | 공유용 집계. 프레임·응답·상태별 수, 표시된 점의 가시성/자세별 수와 제한을 기록한다. 경로·검토자 ID·개별 좌표를 포함하지 않는다. |

이미지를 새로 복사하거나 crop·박스·분할 마스크를 만들지 않는다. 여러 사람이 같은 프레임을
표시해도 하나의 프레임 아래에 각자의 주석을 따로 보존하며, 좌표를 평균내지 않는다.
`point_annotations`는 검토자별 점의 수, `unique_frames_with_points`는 점이 있는 고유 프레임 수다.

| 원응답 | 준비 결과 |
|---|---|
| `marked` + `full` 또는 `partial` | 원본 전체 화면의 `[x,y]`를 보존하고 `candidate_point_mask=true`로 기록한다. |
| `resting` | 별도 자세 속성으로 보존한다. 표시된 점을 제외하는 조건으로 쓰지 않는다. |
| `unavailable` | 점은 `null`, 점 사용 마스크는 false다. 중심 판독 불가이며 글러브 부재 음성이 아니다. |
| `unknown` / `unreviewed` | 각각 별도 상태로 남기며 점은 `null`이다. 좌표 0이나 기권 정답으로 바꾸지 않는다. |

모든 행의 `glove_presence_target`은 `null`이다. 과거 점을 새 규약의 점으로 대신 채우지 않는다.
프레임 그룹 키는 경기를 식별할 뿐 학습/검증 분할을 선택하지 않는다.

## 검증과 남은 사람 작업

CV12 원본 검사기로 원본 라벨·manifest·이미지 SHA/크기를 다시 대조한다. CV6 익명 관측 ID는
검증된 이미지·투구 키·원본 경로·시각에 연결하며 행 순서로 짝짓지 않는다. 중복·변경·모호한
연결은 거절하고, 출력 직전에 소비한 파일의 SHA를 재확인한다. 이는 신뢰하는 로컬 파일의
일관성 검사이며 실제 사람의 신원이나 독립 작업을 인증하지 않는다.

다음 실제 작업은 사람이 기존 26장을 [관측 v1 규약](CV_OBSERVATION_PROTOCOL_V1.md)으로 읽고
응답을 제출하는 것이다. 이전 AI·사람 점을 보지 않은 상태에서 보이는 미트 몸체 중심,
full/partial, 자세를 각각 기록하고, 부분 가림·판독 불가·불확실의 이유를 남긴다.
미검토 행은 그대로 두며 추측으로 채우지 않는다. 각자의 독립 원응답은 서로 보기 전에 보존한다.

응답 한 개부터 준비할 수 있지만 그것으로 사람 간 합의나 독립 정확도를 입증하지 않는다.
가용성 합의를 평가하려면 최소 두 사람의 독립 판단과 별도 불일치 판정 절차가 필요하다.
원응답을 덮어쓰지 않고, 해결되지 않은 판단은 `unknown`으로 유지한다.

**`ready_for_training`은 응답이 들어와도 false다.** 이 도구가 고른 학습 예제는 0개이며,
어느 검토자/판정 라벨을 쓸지, 불일치 처리와 경기별 분할을 어떻게 고정할지는 후속 작업이다.
실패한 CV15 tinyCNN을 재실행하거나 새 학습을 시작하는 명령이 아니다.
CV6 사람 판정과 CV7 미열람 영상·새 독립 라벨러 평가는 계속 미완료다.

검증 범위: 합성 자료 20개 테스트에서 상태·null·resting 보존, 다중 검토자의 고유 프레임 분모,
행 순서 독립 연결, 잘못된 출처/AI 응답 거절, 입력 변경·덮어쓰기 방지와 CLI 집계를 확인했다.
이는 실제 라벨 품질이나 모델 성능 검증이 아니다.
