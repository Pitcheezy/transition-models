# 미트 관측 불일치 26건 — 개발 검토 자료

2026-10-05. 기존 두 경기의 **AI 기권·사람 표시 26건**을 다음 관측 규약으로 재검토하기 위한 준비 자료다. 기존 M3에서 잘못된 기권이었다고 판정한 결과가 아니다. 새 사람 응답과 판정은 아직 없다.

## 대상과 사용 방법

대상은 [품질 감사](results/cv_followup_20261005/quality_audit_v1.json)의 경기 849845 13건, 823407 13건이다. 이 선택은 이미 알려진 불일치를 의도적으로 고른 것이므로 전체 영상이나 새 독립 검증의 표본으로 쓰지 않는다.

로컬 패키지의 `reviewer/`만 검토자에게 제공한다. 여기에 원본 이미지의 익명 사본, `index.html`, source-only manifest, 빈 응답 JSON이 있다. 상위 폴더의 선택 근거 파일은 기존 AI·사람 결과와 연결되므로 함께 제공하지 않는다. HTML을 브라우저로 열어 원본을 보고 빈 JSON에 판독을 기록한다. 원본 방송 화면에 보이는 선수·점수판까지 가린 완전 익명 영상은 아니다.

이 패키지는 기존 AI·사람 좌표나 기권 이유를 보여주지 않는다. 새 검토자는 [관측 v1 규약](CV_OBSERVATION_PROTOCOL_V1.md)에 따라 다음을 분리한다.

- **보이는 미트 중심**: resting 상태라도 중심을 읽을 수 있으면 표시한다.
- **보임 정도**: 전체/부분/모름을 따로 적는다. 보이지 않는 부분을 억지로 추정하지 않는다.
- **자세/의미**: 제시·resting·이동·모름을 위치와 분리한다. 투수 의도를 판단하지 않는다.
- **기권·모름**: 좌표를 0으로 채우지 않고 이유를 적는다.

JSON의 구체적인 허용 값과 필드는 생성된 빈 응답 및 도구 CLI를 따른다. 미검토 행을 자동으로 완료 처리하지 않는다. 이 도구의 응답 검사는 파일 연결·좌표 형식·검토 완료 수를 확인할 뿐 사람의 판단이 옳다는 뜻은 아니다.

## 출처와 보호

준비기는 감사 보고서의 원본 파일 SHA를 확인하고 실제 투구 연결·가용성 불일치를 재계산한다. points·라벨 팩·사람 라벨·JSONL 연결을 확인한 뒤 선택 프레임의 실제 바이트 SHA를 대조한다. 익명 이미지는 원본 바이트를 그대로 복사하며 새 crop·점·확대 표시를 만들지 않는다.

완성된 응답은 reviewer manifest SHA와 관측 ID·이미지 SHA에 연결된다. 중복·누락·다른 이미지·비유한 좌표·이미지 범위를 벗어난 점은 거절한다. 원본 M3·JSONL·사람 라벨은 덮어쓰지 않는다.

이는 **신뢰하는 로컬 파일의 일관성 검사**다. 두 사람이 독립적으로 검토했다는 사실을 도구가 인증하거나 디렉터리 접근을 보안적으로 격리하지는 않는다. 실제 검토자와 독립 작업 여부는 별도로 기록해야 한다.

## 완료 상태와 다음 행동

현재 완료 범위는 원본 검증·검토 패키지·빈 응답 준비다. 26건의 판정은 미검토이며 CV-6 전체를 완료로 바꾸지 않는다.

검토자는 기존 AI·사람 점을 보지 않은 채 새 규약으로 판독하고, 응답 파일을 별도 파일명으로 보존한다. 서로의 응답을 보기 전에 각자 제출한 파일을 유지한다. 이후 불일치를 합의된 절차로 판정하되 원래 응답을 덮어쓰지 않는다. 응답이 없거나 합의가 안 되면 `unknown`을 유지한다.

새 독립 검증은 CV-7에서 미열람 영상·표본 선정 규칙·독립 라벨러를 먼저 고정한 뒤 진행한다. 이 26건으로 개선안을 만들면 해당 자료는 계속 개발 자료다.

## 실제 실행 및 재현

로컬 `outputs/cv_review_20261005/reviewer/index.html`에 26장 원본 자료를 준비했다.
응답 검사 결과는 **완료 0 / 미검토 26 / unknown 0**이다. 두 경기 각 13장이다.
[실행 출처 기록](results/cv_followup_20261005/review_queue_v1.json)에 소스·패키지 SHA와 검증 범위를 고정했다.

프로젝트 Python 환경에서 다음 명령을 실행한다. `prepare`는 기존 폴더를 덮어쓰지 않으므로
재현할 때마다 `outputs/cv_review_`로 시작하는 새 폴더 이름을 사용한다.

```bash
python -m intent.review_queue prepare --report docs/results/cv_followup_20261005/quality_audit_v1.json --out outputs/cv_review_new
python -m intent.review_queue check-response --package outputs/cv_review_new --response outputs/cv_review_new/reviewer/response_template.json
```

실제 사람 응답은 빈 양식과 다른 파일로 저장하고 `--response`에 해당 파일을 지정한다.
검토자에게는 `reviewer/`만 제공하고, 원본 응답을 받으면 관리자 쪽의 원래 패키지와 대조한다.
MLB 프레임은 Git 또는 공개 링크에 올리지 않는다. 다른 컴퓨터에서 다시 준비하려면
원본 로컬 프레임도 있어야 하며 JSON 보고서만으로 이미지를 재생성할 수 없다.

HTML의 이미지 참조 26개·파일 존재·바이트 SHA를 확인했다. 앱 브라우저 보안 정책이
`file:` URL을 거절해 브라우저 렌더링 검사는 하지 못했으며 우회하지 않았다.
페이지는 정적 원본 열람용으로, 점을 클릭해 입력하는 주석 UI는 포함하지 않는다.
