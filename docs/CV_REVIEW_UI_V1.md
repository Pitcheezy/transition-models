### 실행 순서

받은 `reviewer/` 폴더에서 자료를 먼저 검사하고 화면을 켠다. Python 3가 필요하며 개발·검사 환경은 Python 3.12다. 별도 패키지 설치는 필요 없다.

```text
# Mac
python3 start_review.py --check
python3 start_review.py --open

# Windows
py -3 start_review.py --check
py -3 start_review.py --open
```

기존 Windows 저장소 루트에서는 `.\.venv\Scripts\python.exe`로
`outputs/cv_review_20261008_ui_v3/reviewer/start_review.py`를 실행해도 된다.
도우미는 자기 파일이 있는 폴더를 기본 대상으로 삼으므로 다른 작업 폴더에서 전체 경로로 실행할 수도 있다.
`--check`는 자료 검사만 한다. 실제 서버를 실행하면 기본 포트 `0`으로 빈 포트를 고르고
선택한 주소를 표시한다. **그 명령을 실행 중인 컴퓨터**에서 해당 주소를 연다.
`--open`을 넣었을 때만 브라우저를 자동으로 연다. 직접 지정한 포트가 사용 중이면 `--port` 옵션을 빼고 다시 실행한다.
사용하는 동안 터미널을 켜 두고 종료할 때는 `Ctrl+C`를 누른다.

### 입력·중단·제출 순서

1. 검토자 ID를 입력하고 이미지를 본다. 미트 중심·가시성·자세·이유는 실제 사람이 입력한다.
2. 작성 중에는 **작업 초안 저장 · 제출용 아님**을 누르고 다운로드된 파일을 확인한다. 빠진 선택지나 이유를
   고치도록 강제하지 않고 현재 값을 보관한다. 다음에 **저장한 응답 / 초안 불러오기**로 이어서 입력한다.
3. 제출할 내용을 확인한 뒤 **제출용 응답 JSON 내보내기**를 사용한다. 최종 응답의 상태·좌표·가시성·필수 이유는
   기존의 엄격한 검사를 거친다. 입력 중인 행이 검사에 걸리면 사람이 해당 내용을 보완한다.
4. **저장한 응답 / 초안 불러오기** 입력칸 하나가 두 파일을 구분해 불러온다.
   초안을 불러와도 제출용 응답으로 바뀌지는 않는다. 실제 제출에는 최종 응답 JSON을 전달하고 원본을 보관한다.

미검토 행이 남아 있어도 규약상 유효한 응답은 내보낼 수 있다. **초안 저장은 다른 기능**으로,
가시성이나 필수 이유를 아직 입력하지 않은 행도 작업 중 상태 그대로 보관한다.
기본 파일명은 초안 `human_review_draft.json`, 최종 응답 `human_review_response.json`이다.
초안은 최종 응답 제출 검사에서 받지 않는다. 어느 저장도 자동 저장이 아니다.
브라우저를 닫기 전 내려받은 파일을 확인한다.
AI가 판정·좌표·검토자 ID·이유를 대신 입력하거나 기존 사람 응답을 보정하지 않는다.

관리자가 실제 최종 응답을 검사할 때는 원래 상위 패키지를 사용한다.
`path/to/response.json`은 내려받은 최종 응답 경로로 바꾼다. 초안은 이 검사에 제출하지 않는다.

```text
python -m intent.review_queue check-response --package outputs/cv_review_20261008_ui_v3 --response path/to/response.json
```

이관할 때는 도우미를 포함한 `reviewer/` 폴더 전체만 비공개로 제공한다.
상위 `private_selection.json`, 이전 좌표·비교 그림·기존 사람 응답은 함께 제공하지 않는다.
기존 팩·원본 이미지·원응답은 보존한다. MLB 원본 화면은 공개 저장소·공개 링크에 올리지 않는다.
