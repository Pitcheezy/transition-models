## 개발에 반영할 점

1. **미트 픽셀과 변환 좌표의 가용성을 분리한다.** 보이는 미트는 픽셀 단계에 남기고, 보정 정보가 없으면 피트 좌표만 비운다.
2. **프레임 선택과 같은 프레임의 점 판독을 분리해서 평가한다.** 서로 다른 프레임의 좌표 차이를 단순 판독 오차라고 부르지 않는다.
3. **낮은 위치를 휴식이나 목표 부재로 단정하지 않는다.** 사용자 원응답의 자세 값은 보존하며, 동작·제시 여부는 연속 영상과 별도 규약이 필요하다.

이는 이미 [미트 관측 v1 규약](CV_OBSERVATION_PROTOCOL_V1.md)에 정한 분리 방향의 구체적인 근거다.
새 규약·모델·서비스 계약을 추가한 것이 아니다. 새로운 이미지 판독, 연속 영상의 목표 제시 판정,
독립 사람 검토와 CV7의 미열람 영상 평가는 별도로 남는다.

## 실행 방법과 보관

기존 비공개 검토 패키지와 첫 사람 응답이 있는 우리 저장소에서 실행한다. 새 출력 폴더만 허용한다.
필수 원자료가 없거나 SHA가 다르면 중단하며, 빈 자료나 합성 응답으로 대신하지 않는다.

```text
python scripts/audit_cv6b_saved_reasons.py --repo-root . --out outputs/cv_review_routes_20261008_v1
```

`private_row_audit.json`은 내부 연결 근거, `public_summary.json`은 개인 식별자·개별 좌표·비공개 경로를 뺀 집계다.
비공개 행은 Git에 포함하지 않는다. 감사 도구는 입력·M3·사람 응답·학습 선택을 변경하지 않는다.

CV-6b의 저장 경로 감사는 완료한다. CV-6의 시각적 원인 확정·두 사람 합의와 CV7은 완료로 바꾸지 않는다.
