선택기는 CV42의 고정 저장 관측을 재생해 검증할 수 있지만 픽셀 추적·OCR·새 모델 판독은 실행하지 않는다. 기존 재탐색과 게이트 기록 모두625행·키·manifest시각·JPEG SHA·저장 선택 상태를 검사한다. 첫 구의 OCR74행만 재사용하고 나머지551장은 관측 없음으로 표시한다. OCR envelope의 미관측 투구 목록은2→9구로 확장하며 판독 행 자체는 보존한다.

별도 내부 `comparison_schema=pitcheezy-seed-gate-frame-comparison-dev-v1`을 사용한다. 이는 공개 발행 파일/IntentEstimate 계약 변경이 아니다. 기존 baseline/reacquire 팩과 새 seed_gate 팩의 라벨·허용 모드를 구분하고 잘못된 결합은 거부한다.
