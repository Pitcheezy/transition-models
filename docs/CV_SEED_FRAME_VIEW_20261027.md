# CV43 — 초기점 게이트의 채택·보류 근거 재생

## 범위와 합격 기준

기준은 CV42 PR78 `7d49f82`, 작업 브랜치는 `codex/cv-seed-view-1027`이다. [착수·합격 기준](https://github.com/Pitcheezy/transition-models/issues/3#issuecomment-6423682631). 기존 PA3 203장 팩은 보존하고 고정10구625 JPEG를 새 비공개 개발 화면에 연결한다.

왼쪽/오른쪽 두 시각을 비교하는 대신 같은 프레임에서 `기존 재탐색`과 `초기점 게이트`를 바꿔 본다. 방식 변경은 재생을 멈추며 투구·프레임을 유지한다. 현재 프레임의 게이트 상태·사유·지지 관측만 보여 주고 미래의 채택 결과를 미리 채우지 않는다. 시드 점 자체를 확정 미트처럼 그리지 않는다. 현재 추적·멈춤점과 과거 발생 기록은 각각 자기 이미지에 표시한다.

선택기는 CV42의 고정 저장 관측을 재생해 검증할 수 있지만 픽셀 추적·OCR·새 모델 판독은 실행하지 않는다. 기존 재탐색과 게이트 기록 모두625행·키·manifest시각·JPEG SHA·저장 선택 상태를 검사한다. 첫 구의 OCR74행만 재사용하고 나머지551장은 관측 없음으로 표시한다. OCR envelope의 미관측 투구 목록은2→9구로 확장하며 판독 행 자체는 보존한다.

별도 내부 `comparison_schema=pitcheezy-seed-gate-frame-comparison-dev-v1`을 사용한다. 이는 공개 발행 파일/IntentEstimate 계약 변경이 아니다. 기존 baseline/reacquire 팩과 새 seed_gate 팩의 라벨·허용 모드를 구분하고 잘못된 결합은 거부한다.

## 확인할 장면

- 보류된 PA3 1구: 기존 재탐색이 점을 표시하는 프레임에서도 게이트 방식은 시드가 없음을 구분한다. 같은 이미지의 OCR 상태는 보존한다.
- 채택된 PA4 2구: 원본20494 전에는 지지 관측을 모으며 현재 점 없음,20494에서만 초기화,20512에서 기하학적 멈춤 조건 충족.
- 같은 투구20710 탐색과20734 소실: 현재 점 없음·과거 기록은 자기 발생 프레임만.
- 뒤로 탐색·방식/투구 전환·늦은 이미지·오류에서 이전 점·게이트·OCR 상태가 잔존하지 않는지 검사한다.

## 결과와 한계

구현·실행 결과는 검증 후 추가한다. 화면은 저장 개발 결과의 설명 도구다. 채택4구의 미트 식별, 보류6구의 정당성, 물리 좌표·투수 의도·온라인 가용성을 검증한 결과가 아니다. AI 합의를 사람 정확도나 독립 평가로 세지 않는다. 독립PTS·CV35/36·A-y/F-4i·실기기 조건은 그대로다.
