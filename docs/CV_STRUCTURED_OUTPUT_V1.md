## 변경 범위

`scripts/observe_claude_frame.py --structured-output`을 선택하면 CLI JSON Schema와
최종 structured_output을 사용한다. 요청 ID/이미지 해시·필드 형식은 스키마에 고정하며,
상태·좌표·가시성의 교차 조건과 좌표 범위는 기존 엄격한 검증기가 계속 확인한다.
최종 응답과 일치하는 내부 StructuredOutput 직렬화 호출/결과 쌍만 예외적으로 허용한다.
다른 도구, 식별자 불일치, 문자열 좌표, 누락 결과를 자동 보정하거나 텍스트로 대체하지 않는다.
기본값은 기존 방식이며 구조화 모드는 선택 기능이다.
