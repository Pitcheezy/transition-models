# CV-39a — 추적·멈춤 후보의 비공개 프레임 재생

## 착수 합격 기준

2026-10-26 사용자 요청으로 CV38 검토 대기 중 분리된 작업 폴더/브랜치 `codex/cv-frame-view-1026`에서 화면만 병행한다. 기준 `a42c044`, CV38의 검토 미완료를 완료로 승격하지 않는다. 팀원·운영·원본 Claude 폴더는 변경하지 않는다.

- 기존 CV37/CV38 보고 SHA→저장 행 SHA→CV32 manifest SHA→timing SHA→원본 JPEG SHA를 연결한다. 전체625행의 투구 키·프레임·시각·현재/과거 출력을 확인하고 첫 완전한 타석 PA3의3구203장만 화면에 쓴다. 후보가 좋은 구만 고르지 않는다.
- 현재 추적과 현재 멈춤 후보는 주 화면, 과거 후보는 자신의 발생 프레임을 별도 패널로 표시한다. 소실/로딩/오류 중 현재 점 없음, 미래 사건 누출 없음, 늦은 이미지 응답은 무시한다.
- 프레임/투구 이동·재생/정지·시간 탐색·키보드를 제공한다. 투구 전환은 정지/초기화하고 투구 사이 빈 구간을 보간하지 않는다. 원영상이 아닌 저장 JPEG 재생이라고 표시한다.
- 잘못된 키/중복/누락/시각/해시/해상도/좌표/역사 연결은 생성 전에 거부한다. 새 폴더만 만들고 기존 입력·산출물을 보존한다. 외부 URL/원본 media_url/개인 경로를 화면에 복사하지 않는다.
- 자동 경계 검사와 실제 로컬 브라우저 확인, 고정 소스 Claude 검토를 수행한다. 의미는 개발용 기하학적 추적이다. 미트/목표/의도 정확도·독립 PTS 검증·실시간 동작으로 부르지 않는다.

묶음에는 원본 MP4·독립 showinfo/PTS 로그가 없으므로 시각은 manifest 기반이다. OCR은 이 묶음과 다른 캐시 영수증 규격을 쓰므로 CV39b로 분리한다. 가짜 OCR 영수증·새 사람 라벨·AI 판독은 만들지 않는다. 전체 CV39 완료로 표시하지 않는다.

여기서 타석 연결은 같은 PA의 모든 **투구 키**를 탐색한다는 뜻이다. 타자 입장부터 퇴장까지 연속 영상이 확보됐다는 뜻이 아니며, CV5a의 엄격한 전체 타석 조건을 해제하지 않는다. 각 투구는 저장된 투구 전 격자 프레임만 표시한다.
