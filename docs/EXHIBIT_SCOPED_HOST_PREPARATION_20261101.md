## 승인 단계 1 — 새 빈 저장소만 생성

합격: 조회로 새 자원 ID를 확인하고 새 DB 초기 테이블을 확인한다. 실제 이름·DB ID는 비공개 영수증에만 기록한다. 유지 설정은 Workers Free, 준비 예산 월 $10 이내이며 자동 청구 상한이라고 쓰지 않는다. 오류 시 다음 단계로 진행하지 않고 연결되지 않은 빈 자원을 그대로 보존한다. 자동 삭제·비용 발생 설정 변경은 하지 않는다.
