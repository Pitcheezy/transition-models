## 1. 결론

- **합의에 걸리지 않는 것만 남기면 V5의 화면은 v0(Song이 준 c47 고정 빌드)와 똑같다.** V4의 전 버전인 V3도 index.html 태그 3개, theme-color 값, 외부 구매 모델로 이미 합의에 닿아 있어서, 걸리는 것을 빼면 v0가 남는다.
- **Song 동의 없이 관람객 눈에 보이는 것을 바꿀 방법은 없다.** 색 링크 한 줄만 넣어도 Song의 index.html이 659 B에서 712 B(계산, 그런 파일은 아직 만들지 않음)로 달라져 우리 11/1 약속 "네 index.html 그대로"(댓글 6555601601)가 깨진다.
- V3 바탕의 장점은 분명하다. Song의 JS·CSS가 바이트 그대로라 V4에 없던 주기 확인, 긴급 안내 숨김과 복원, 세션 만료 알림, 재시도, "기준과 한계" 시트, 메인 존 미트 표시가 따로 손대지 않아도 남는다(SHA 대조는 계산, 덧입힌 상태의 동작은 판독).

## 4. 점검에서 새로 나온 사실

- `pz-theme.css`에는 3D 상자 규칙(61~68행)이 섞여 있어 테마만 내려면 잘라 내야 한다. 색 부분(6~59행)은 크기·간격 속성 0건이다(직접 스캔).
- V3 배포 꾸러미는 index.html을 고치고 `pz/`를 더했는데도 프런트엔드 출처를 Song 빌드로 선언했다. 검사기는 index.html 바이트를 Song 것과 대조하지 않는다.
- 검사기는 임시 허용 없이 A와 색 테마 판은 통과시키고, 3D 판과 V4는 `.glb`와 출처 규칙으로 거부한다(계산).
- NOTES의 "pz-theme.css 3.8 KB, pz-batter.js 9.5 KB"는 검토 반영 전 값이다. 현재 5,483 B와 12,006 B다.
- 공개 폴더에는 Song 4파일 외에 우리 설정 파일 1개가 함께 나간다. Song에게 바이트 대조 범위를 말할 때 구분해 적어야 한다.
