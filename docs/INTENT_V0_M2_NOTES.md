# 의도 모듈 v0 — M2 기록: annotated_image_zone → plate_feet (2026-10-01, Claude Fable 5.1 세션)

작업 지시서 [INTENT_V0_WORK_ORDER.md](INTENT_V0_WORK_ORDER.md)의 M2(정규화 좌표 → 홈플레이트 피트 좌표, 변환 행렬·방법·`rms_error_feet`·`fit_evidence`)를
경기 747139(SNY 중앙 카메라, 1280×720, SAR 1:1, 59.94 fps)에서 구현·측정한 기록이다. 모든 판독은 Claude Code 워크플로 에이전트의
시각 추정(`assistant_visual_estimate`)이며 **사람 검토는 없다**. 숫자는 이 경기(개발 경기) 안에서 잰 값이고 다른 경기 성능이 아니다.

## 1. M1에서 바뀐 것 — 홉 ①

M1의 홉 ①은 플레이트 네 모서리 → 단위 정사각형 평면 homography였다. 미트는 플레이트 평면 위에 있지 않으므로 그 v값은 의미가 없었고
(−10 ~ −2000), 플레이트가 화면에서 4 px 높이라 수치도 불안정했다. M2의 홉 ① **v1**은 플레이트 **앞선(17 in)** 에 고정한 2차원 유사변환이다.

- u = 앞선 중점 기준 가로 위치(앞선 폭 단위, 0 = 왼쪽 끝, 1 = 오른쪽 끝), v = 그 지면선에서 위로 올라간 거리(앞선 폭 단위).
- 카메라 롤은 프레임별이 아니라 M1 모서리 165프레임의 앞선 방향 중앙값(상수)으로, 배율(앞선 px)은 같은 타석 프레임들의 중앙값으로 쓴다
  (프레임 값이 타석 중앙값과 8% 이상 다르면 그 프레임 값). 뒤 모서리는 진단(틸트 추정·가로 어긋남)에만 쓴다.
- `inside_annotated_quad` := 0 ≤ u ≤ 1 이고 0 ≤ v ≤ 3(플레이트 폭 3배 = 4.25 ft 이하). 스트라이크존 판정이 아니다.

## 2. 홉 ② — 상수 3×3 아핀 행렬

```
plate_x_ft = -(17/12) · (u − 0.5)
plate_z_ft =  (17/12) · v / cos θ  −  d0 · tan θ
```

- `x_convention = statcast_plate_x_catcher_view`: 포수 시점에서 오른쪽(1루 쪽)이 양수. 중앙 카메라는 투수 쪽에서 포수를 보므로 화면 오른쪽 = 3루 쪽 = 포수의 왼쪽 = 음수 → 부호가 뒤집힌다(우타자가 화면 오른쪽에 서는 것과 일치).
- 세로 배율 = 가로 배율 ÷ cos θ (핀홀, 정사각 화소). θ는 카메라 하향 틸트.
- `d0·tan θ`: 미트는 플레이트 앞선보다 d0 ≈ 2.5 ft 뒤에 있어서 같은 높이라도 화면에서 d0·sin θ만큼 높게 보인다(깊이 시차). 공칭 깊이 2.5 ft(가정, 미측정)에 대해 제거한다.
  → `plate_feet.y`의 목표량은 **미트 자체의 높이**(그 깊이에서)이지, 그 미트로 들어오는 공의 플레이트 앞선 통과 높이가 아니다. 공이 앞선에서 미트까지 떨어지는 양(0.15~0.4 ft)과 상쇄시키지 않는다.
- 행렬 값(보정 파일에 기록): tilt_sin = 0.1017, d0 = 2.5 → `[[-1.41667, 0, 0.70833], [0, 1.42406, -0.25569], [0, 0, 1]]`. 보정 파일이 없으면 tilt 0·d0 0의 무보정 행렬을 쓰고 transform 단계에 그렇게 적는다.

## 4. 오차 측정

### 4-1. 방송 K존 오버레이로 세로 배율 검증(결정 프레임 30개, 판독 45건)

오버레이 폭/플레이트 앞선 폭 = 0.987. 오버레이 높이를 가로 배율로 피트로 바꾼 값 ÷ feed의 그 투구 `strikeZoneTop−Bottom` = **1.001 ± 0.007**(SD 0.05).
즉 세로 배율은 가로 배율과 같다(핀홀 가정 검증). 오버레이는 플레이트 앞선보다 0.12 ft 위(= 플레이트 안쪽 더 깊은 지점에 그려짐)에 있어 원점으로는 쓰지 않는다.
(설계 노트 초안에서 눈대중으로 "오버레이 세로 배율 1.3배"라고 적었던 것은 이 측정으로 틀렸음이 확인됐다.)

### 4-3. 끝단 검증 — 포구 프레임의 공 위치 vs Statcast 궤적

콜드 스트라이크·볼(스윙 없음) 가운데 릴리스 시각이 있는 투구를 타석당 하나씩 24구 고르고, `release_seconds + plateTime` 기준 −0.20 ~ +0.40 s의 9프레임을 추출했다.
두 판독자가 **공이 미트에 들어간 첫 프레임**을 고르고 그 프레임의 공/포켓 중심과 플레이트 앞선을 읽었다. 홉 ①·②(보정 행렬)로 피트로 바꾼 값을
feed의 9변수 궤적을 미트 깊이(Statcast y = −1.0 ft, 앞선 뒤 2.4 ft; 민감도 −0.5·−1.5 ft)에서 평가한 공 위치와 비교한다.

- 표본 24구 중 사용 21구, 제외 3구(PA33/1: A: No frame shows the ball settled in the glove: it passes t; PA50/1: A: No catch: the pitch bounced in the dirt before the plate,; PA55/1: B: Every frame is post-catch: at -0.20 the ball is already s).
- 두 판독자 불일치(같은 투구, ft): x SD 0.176, z SD 0.198, 같은 프레임 선택 비율 0.62.
- 선택된 '공이 미트에 들어간 첫 프레임'의 오프셋(릴리스+plateTime 기준) 평균 0.022 s — 수동 릴리스 시각의 포구 시각 잔차.
- 카메라 틸트 sin θ = 0.1017 (θ = 5.84°, n = 48), 공칭 깊이 2.5 ft의 시차 보정 0.256 ft.
- **`rms_error_feet` = 0.325 ft** (`error_status` = measured, 사람 확인 0구). 평균 부호 오차(편향)와 SD를 따로 보고, rms는 그 파생값으로만 쓴다.
- '무보정 z 오차 평균'은 시차 항을 빼지 않았을 때의 값(진단)이다; 보정 후 z 편향이 0에 가까우면 공칭 깊이 가정이 이 경기의 포구 깊이와 맞는 것이고, 남는 편향은 깊이 차이·판독 공통 편향·포구 시 미트 이동의 합이다.

**해석(2026-10-02 기록).**
- z: 시차 항을 뺀 뒤 평균 편향이 +0.37 → +0.12 ft로 줄었다. 남은 +0.12 ± 0.04 ft는 공칭 깊이 2.5 ft가 실제 포구 깊이와 다르거나(깊이 1 ft당 약 0.10 ft), 궤적 평가 깊이(y = −1.0)와의 차이, 포구 순간 미트 이동이 섞인 값이다. 기울기 0.94 ± 0.03은 세로 배율이 약 6% 작다는 뜻이 아니라 높은 공일수록 더 멀리서(깊게) 잡히는 효과까지 포함한 값으로 본다.
- x: −0.17 ± 0.04 ft(2 in)의 일정한 편향이 남는다. 러버-플레이트 가로 어긋남(−35 px, 60.5 ft 지렛대)으로 잰 카메라 팬은 0.8°라 깊이 시차는 0.03 ft뿐이고, 지면 분필선(d=0)에서는 편향이 없으므로 변환 자체의 원점 오차는 아니다. 남는 후보는 반쯤 가려진 공의 중심을 보이는 쪽으로 찍는 판독 편향, 포구 직후 미트 이동, Statcast와 카메라의 가로 정합 차이다. 원인을 모르므로 **행렬에 넣지 않고** 그대로 보고한다(M3에서 사람 판독으로 가린다).
- 판독자 불일치가 0.5 ft를 넘는 투구 1구(PA74/1: 두 판독자가 다른 프레임·다른 공 위치)는 사전에 제외 규칙이 없어 평균값으로 그대로 포함했다. PA69/1은 1차 판독에서 한 판독자가 '바운드 후 집어 든 공'으로 보았으나 재실행 판독에서는 두 판독자가 +0.10 s의 같은 위치를 포구로 읽었고 Statcast 위치와 일치해 포함했다(판독 원문은 readings 파일에 모두 남아 있다).
- 한도 재설정 뒤 재개한 워크플로가 7개 에이전트를 다시 돌렸고(실패 3 + 재실행 4), 같은 묶음의 판독이 바뀐 경우 마지막 판독을 썼다. readings 파일의 critique 항목에 설계 비판 패널 3건이 그대로 들어 있다.

### 4-4. `rms_error_feet`의 뜻

`intent.run`이 홉 ② 단계의 `error`로 쓰는 값은 4-3의 y = −1.0 ft 2차원 rms다. 포함: 판독 잡음(포켓·앞선), 배율·원점 오차, 공칭 깊이 가정과 실제 포구 깊이의 차이(시차·궤적 양쪽).
미포함: 셋업 프레임의 미트 중심 판독 잡음(±10~15 px ≈ ±0.3~0.4 ft, M1 값 그대로), 셋업 깊이와 포구 깊이의 차이, 사람 검토. 10구 미만이면 null.

## 6. 한계와 다음(M3)
