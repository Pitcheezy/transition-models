## 확인한 문제와 수정

1. **미완료 연결이 전체 서버를 멈춤.** 단일 `HTTPServer`에서 헤더 또는 본문을 끝까지
   보내지 않은 연결 하나가 `/api/health`를 포함한 후속 요청을 막았다.
   `ThreadingHTTPServer`로 연결을 독립 처리하고 소켓 읽기에 5초 제한을 둔다.
   모델 계산만 잠금으로 직렬화해 한 모델 인스턴스의 동시 사용을 막는다.
2. **잘린 본문을 정상 요청으로 처리할 수 있음.** 선언한 Content-Length보다 적은 바이트를
   받은 뒤 연결 쓰기가 닫혀도, 받은 부분이 `{}`처럼 유효한 JSON이면 추론을 호출했다.
   실제 바이트 수가 다르면 400, 본문 읽기 시간 초과는 408을 반환한다.
3. **모호한 본문 길이 처리.** 중복 Content-Length 또는 Transfer-Encoding이 있는 요청을
   명시적으로 거부한다. 브라우저가 정상 전송하는 JSON 요청 형식은 그대로 지원한다.

계산 도중 사용자가 탭을 닫는 연결 해제는 정상 종료로 처리해 불필요한 500 응답 시도를 막는다.
