# 운영·확률·정책 검증 실행 계획

테스트 결과를 보기 전에 정한 비교 규칙이다. 기존 산출물은 보존한다.

1. 관측 투구 77d/135d 비교는 기존 seed 42에 43, 44를 추가한다.
2. 운영 특징은 2022년 자료로만 만든 고정 과거 프로필을 사용한다. 모델 학습은 2023년,
   선택/early stopping은 2024년 1–5월, calibration은 6월, 최종 test는 7월 이후다.
3. 상태는 count, outs, 주자, inning, 타자/투수 handedness 및 알려진 투수 ID다.
   행동은 구종이다. 현재 투구의 실제 위치·구속·회전·궤적·결과는 입력하지 않는다.
   물리량과 zone 분포는 과거 pitcher/pitch-type의 shrinkage 통계로 추정한다.
4. 운영 77d/135d는 동일한 생성기를 학습·평가·시연에서 공유한다. 운영 135d의 58개 추가
   변수는 2022년 repertoire(17), 물리량 평균(15)/표준편차(15), 결과 발생률(10), 표본 수(1)다.
   기존 UMAP/Arsenal 135d와 의미가 다른 명시적 새 schema이며 기존 checkpoint에 넣지 않는다.
5. LR/LGB/MLP 및 경험적 조건부 확률 기준선을 CE 우선, Brier 보조로 비교한다.
   MLP는 seed 42/43/44를 사용한다. 보정은 6월에만 fit한다. 상황별 희소 확률과 경기 단위
   bootstrap, seed 변동을 함께 보고한다. test 성적으로 모델이나 정책 설정을 고르지 않는다.
6. 정책 검증은 구종 추천의 한 번의 결정에 대한 run expectancy 변화다. 2022년의 실제
   inning 결과로 base-out-count 기대 실점을 만들고 실제 다음 상태/득점에서 비용을 계산한다.
   경험적 모델과 학습 모델의 추천을 같은 지원 행동 집합에서 비교한다.
   평가 결과는 보지 않은 test 경기의 기록과 별도 nuisance 모델을 이용한 off-policy 추정으로
   확인한다. 겹침/표본 유효크기/가중치 민감도와 경기 bootstrap을 함께 공개한다.
   정책 평가 모집단은 1–8회 완료된 half inning으로 한정해 끝내기 경기의 결과 의존 종료를 피한다.
   세부 설정: 2022년 30회 이상 던진 9개 주요 구종 중 추정 propensity가 0.02 이상인 행동,
   후보 2개 이상인 상태에서 최소 예상 비용 구종 90% + 후보 균등 10% 정책을 비교한다.
   주 분석은 unclipped doubly robust 추정이고, 가중치 상한 5/10/20 및 SNIPS를 보조 보고한다.
7. 관측자료의 조건부 교환가능성·지원집합 가정을 명시한다. 독립 평가에서 개선이 확인되지
   않으면 효용 입증 실패로 보고한다. 양의 성과를 만들기 위해 test 설정을 변경하지 않는다.
8. 실제 제구 목표 좌표나 무작위 배정 데이터가 없으므로 코스 추천의 인과효과 및 시즌 전체
   실점 감소를 주장하지 않는다. 구종 추천의 검증된 범위와 시연을 완성한다.
