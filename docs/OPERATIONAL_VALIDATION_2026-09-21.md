## 2. 기준선 복구와 반복 실험

과거 77d 벡터와 10-class 정답의 순서가 달랐다. 투구 ID는
`(game_pk, at_bat_number, pitch_number)`이며, 중복·누락·split 중복을 거부한다.
LR/LGB/MLP를 다시 학습했고, 아래 반복은 동일한 관측 투구 특징·평가 행에서 수행했다.

| 관측 특징 모델 | seed 42 CE | seed 43 CE | seed 44 CE | 정확도 범위 |
|---|---:|---:|---:|---:|
| MLP 77d | 0.851689 | 0.851593 | 0.852310 | 67.62–67.67% |
| MLP 135d | 0.854578 | 0.852084 | 0.851544 | 67.60–67.71% |

135d−77d 평균 CE 차이는 +0.000872, seed·경기를 함께 재표집한 95% CI는
**[−0.000687, +0.002801]**다. 세 seed만으로 학습 변동을 정밀 추정할 수는 없다.
과거의 “41.1% → 67.6%, 맥락 효과 +26.5pp” 주장은 철회한다.
LR/LGB 복구와 과거 손실 설정 진단은 [정렬 복구 보고서](ALIGNMENT_REPAIR_2026-09-21.md)에 있다.
구형 상류 UMAP/Arsenal의 정확한 학습 출처는 여전히 미확정이다.

## 4. 확률 중심 선정 결과

검증 CE가 가장 낮은 **운영 135d MLP 3-seed 앙상블**을 최종 평가 전에 선택했다.
아래 모든 모델은 6월 데이터에서만 scalar temperature를 fit했다.
MLP는 42/43/44의 확률 평균, LR/LGB는 seed 42다. LR은 2023 학습 행 전체를 사용했다.
Brier는 10개 클래스 오차 제곱의 합이며, ECE는 15개 등간격 bin의 top-label ECE다.

| 모델 | 정확도 | CE ↓ | Brier ↓ | ECE ↓ |
|---|---:|---:|---:|---:|
| 경험적 조건부 확률 | 45.23% | 1.287400 | 0.659526 | 0.008113 |
| LR 77d | 45.31% | 1.278760 | 0.658599 | 0.010977 |
| LightGBM 77d | 45.43% | 1.276610 | 0.657190 | 0.006835 |
| LightGBM 135d | 45.40% | 1.276912 | 0.657143 | 0.006680 |
| MLP 77d ensemble | 45.51% | 1.274636 | 0.657025 | 0.008441 |
| **MLP 135d ensemble** | **45.51%** | **1.274251** | **0.656815** | **0.007569** |

경험적 기준선은 2023년의 state×action×좌우 조건부 빈도다.
표본이 작은 셀은 count×action×좌우, action×좌우, 전체 빈도로 차례로 축소한다.
단순한 최빈 클래스보다 강한 비교 기준이며 smoothing strength는 50으로 사전 고정했다.

- 선택 모델−경험적 CE 차이: **−0.013149**, 경기 bootstrap 95% CI **[−0.013744, −0.012551]**.
- 같은 차이의 Brier: **−0.002711**, CI **[−0.002905, −0.002526]**.
- 고정 앙상블 135d−77d CE: −0.000385, 경기 CI [−0.000596, −0.000188].
- 개별 학습의 raw CE 차이를 seed·경기 함께 재표집하면 −0.000214,
  CI **[−0.000812, +0.000308]**. 학습 변동까지 고려한 일반적 우월성은 확인되지 않았다.

보정은 test CE 개선을 보장하지 않는다. LR/LGB는 6월 보정 후 test CE가 미세하게 나빠졌고
그 결과도 그대로 포함했다. 모델/온도를 test에서 다시 선택하지 않았다.

## 5. 희소 사건과 상황별 검증

| 사건 | 선택 모델 평균 확률 | 실제 빈도 | 실제 건수 | argmax 예측 수 |
|---|---:|---:|---:|---:|
| Single | 3.6069% | 3.6503% | 12,486 | 0 |
| Double | 1.1712% | 1.0949% | 3,745 | 0 |
| Triple | 0.1062% | 0.0936% | 320 | 0 |
| HomeRun | 0.8249% | 0.8084% | 2,765 | 0 |

**argmax recall 0과 사건 확률 0은 다르다.** 전체 평균이 비슷해도 상황별 calibration이
완벽하다는 뜻은 아니다. Double·Triple의 평균 과대 추정은 경기 CI에서도 0을 벗어났다.
Ball 과대/Strike 과소 추정도 남았다. 클래스별 등빈도 reliability bin을 함께 저장했다.

12개 카운트, 24개 주자×아웃, 구종, 좌우 조합별 CE/Brier/클래스 확률을 집계했다.
표본 100개 미만 상황은 요약 비교에서 제외했고, 희소 사건 잔차 CI는 경기 단위 500회,
주요 전체 지표는 2,000회 재표집했다. 예를 들어 3볼 0스트라이크 3,330투구의
홈런 예측은 0.425%, 실제는 0.691%였다. 하위집단 점검은 탐색적이며 다중검정으로
확증한 발견이 아니다. 전체 결과는 [probability_report.json](results/operational_20260921/probability_report.json)에 있다.

## 6. 끝까지 실행한 정책 평가와 미달성 결론

목표는 한 번의 **구종 선택**이 기대 실점 비용을 줄이는지 비교하는 것이다.
2022년 완료된 1–8회 half inning에서 base/out/count 기대 실점 R을 만들고,
실제 평가 결과의 비용을 `해당 투구 득점 + R(다음 상태) − R(현재 상태)`로 계산했다.
이 비용은 상태 기대값의 변화이며 이닝 총 실점 그 자체가 아니다.

두 정책은 같은 2022년 outcome→비용 kernel과 지원 행동 집합을 사용한다.
9개 주요 구종 중 해당 투수가 2022년에 30회 이상 던지고, 별도 propensity 모델의
확률이 0.02 이상인 후보가 2개 이상일 때만 추천한다.
최소 예측 비용 구종 90% + 지원 후보 균등 10% 정책을 양쪽에 똑같이 적용했다.

독립된 propensity 분류기는 **행동/그 행동의 물리량을 제외한** 상태 31d+과거 프로필 58d로
2023년에 학습했다. 별도 run-cost 회귀 모델도 2023년에 학습했고 1–5월로 선택했다.
최종 7–9월 기록에는 학습/설정 선택을 하지 않았다. DR은 이 별도 보조 모델의 예측을
기록된 행동과 실제 비용으로 보정하는 off-policy 추정이다.

평가 가능 투구는 **195,066개 / 1,165경기**, 최종 분류 평가의 **57.03%**다.
1–8회 완료 이닝과 행동 지원 조건 때문에 제외된 나머지에 일반화하지 않는다.

| 항목 | 결과 |
|---|---:|
| 경험적 정책과 추천 구종이 달라진 비율 | **63.07%** |
| 경험적 정책 DR 비용 / 100회 결정 | +0.1424 |
| 학습 정책 DR 비용 / 100회 결정 | +0.0562 |
| 학습−경험적 비용 차이 / 100회 결정 | **−0.0862** |
| 차이의 경기 bootstrap 95% CI | **[−0.4046, +0.2304]** |
| 경험적 / 학습 정책 가중치 유효 표본 수 | 29,546 / 36,808 |
| 9개 구종 특징 생성+학습 모델 예측 CPU 중앙값 / p95 | **73.4 / 83.1 ms** |

가중치 상한 5/10/20의 차이는 각각 −0.0105/−0.0426/−0.0724점이며 **모든 CI가 0을 포함**했다.
Unclipped SNIPS 차이도 −0.0720점/100회 결정이다. 평균 중요도 가중치는 경험적 0.933,
학습 1.015로 추정 propensity가 완벽하지 않음을 보여 준다.

따라서 **실점 개선 입증은 실패했다.** 확률 점수가 개선되고 추천이 달라져도
정책 효용이 자동으로 입증되는 것은 아니다. 타자 능력·투구 의도 등 관측하지 않은
교란요인이 남아 조건부 교환가능성도 검증하지 못했다. CI는 정책·보조 모델을 고정하고
경기를 재표집한 것이므로 정책 학습 불확실성을 전부 포함하지 않는다.
실제 경기 인과효과, 전체 시즌 절감, 완전한 MDP/DQN 정책 가치로 확대 해석하지 않는다.

추론 시간은 모델을 메모리에 로드한 뒤 CPU 3 threads에서 30회 측정했다.
파일 읽기·서버 통신·propensity 후보 필터·전체 RL 최적화 시간은 포함하지 않는다.
다음 실험은 별도 미사용 시즌/개입 데이터에 사전 등록해야 하며, 이번 test를 보고
행동 제한이나 모델을 바꿔 양의 결과만 고르는 방식은 사용하지 않는다.

## 7. 실행과 시연

저장소 루트에서 실행한다. `uv sync`로 환경을 준비하고 원본 2022–2024 parquet가 있어야 한다.
각 출력 경로는 새 경로여야 한다. Windows, Mac, Linux에서 같은 Python 실행기를 쓸 수 있다.

```bash
# 운영 데이터 생성 → 9개 모델 → 독립 calibration → 정책 평가 → HTML 시연
uv run python scripts/55_run_operational_validation.py --data-dir data/operational_new --run-dir outputs/operational_new --device auto --threads 4

# 현재 학습된 모델로 실제 상태 JSON에서 구종 추천
uv run python scripts/57_recommend_operational.py --data-dir data/operational_20260921_v2 --evaluation-dir outputs/operational_20260921/evaluation --nuisance-dir outputs/operational_20260921/policy_nuisance_v2 --state-json docs/results/operational_20260921/example_state.json

# 현재 결과를 이용한 오프라인 시연 재생성
uv run python scripts/56_build_validation_demo.py --evaluation-dir outputs/operational_20260921/evaluation --policy-dir outputs/operational_20260921/policy --output outputs/operational_20260921/demo_copy.html
```

세부 실행기는 51(데이터), 공통 `src.training.point_baselines`(학습), 52(보조 모델),
53(확률), 54(정책), 56(HTML), 57(실제 추론)이다. 각 `--help`에 필수 인자가 있다.
관측 77d/135d 세 시드 비교까지 다시 집계하려면 53에
`--observed-runs outputs/alignment_repair_20260921 --observed-data data/aligned_20260921`을 추가한다.

- [오프라인 시연](results/operational_20260921/demo.html): 브라우저에서 열고 30개 평가 사례를 선택한다.

- [데이터 명세](results/operational_20260921/dataset_manifest.json), [전체 특징 일치 점검](results/operational_20260921/feature_identity_audit.json).
- 데이터 `data/operational_20260921_v2/`, checkpoint/예측 `outputs/operational_20260921/`는 대형 파일이라 Git 제외다.
  이 Git 저장소만 복제하면 학습 결과가 자동 이동하지 않으므로 재학습하거나 이 두 폴더를 별도로 옮긴다.
  유지보수 보완으로 옛 Windows 경로를 run 이름으로 복원한다. 위치가 다르면
  54/57 실행기의 `--runs-dir`로 지정한다. [이관 안내](MAINTENANCE.md) 참조.

- 미래 날짜, 현재 투구 물리량/결과 차단, 동일 특징 생성, 오래된 checkpoint/schema/hash 거부를 검증했다.
- 지원 행동, 실제 득점·다음 상태 비용, 올바른 propensity 또는 올바른 회귀식이 주어진 DR 계산을 검증했다.
- 저장된 평가 사례와 실제 CLI 추론을 실행했고, HTML에서 사례를 바꿔 추천·확률 갱신을 확인했다.
- CPU 실제 추론과 저장된 test 확률 1,000행을 비교한 최대 절대 오차는 8.31e-8 미만이었다.
- 문서의 맥락 효과 입증·장타 확률 0·MDP 최선 표현을 철회/수정했다. 과거 기록에는 정정 표시를 붙였다.
- 신규 학습 결과가 기존 rl-agent 기본 checkpoint를 자동 교체하지 않는다. 10-class 결과 확률만으로
  주자 진루·아웃·모든 MDP 전이의 완전한 결합분포를 모델링했다는 뜻도 아니다.

캡스톤에서 방어 가능한 기여는 **정렬 오류 복구, 동일 코호트 비교, 정보 시점 통제,
확률 검증과 정책 평가의 분리, 재현 가능한 실패 결과와 실제 시연**이다.
“최고의 추천 정책”이나 “실점 감소를 입증한 서비스”라고 발표할 근거는 아직 없다.
