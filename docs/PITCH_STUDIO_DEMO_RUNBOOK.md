# 10/6 우리 CV 발표 — 사이트 포함 오프라인 동선

2026-10-05. 새 홈페이지를 포함한 우리 발표 동선이다. 목표 약 2분이며 실제 낭독 시간은
아직 측정하지 않았다. Song의 전체 5분 시연, 실제 서비스·기기 리허설과 별개다.

## 먼저 열기

전달 ZIP 전체를 압축 해제한 뒤 `START_HERE.html`을 브라우저로 연다.
홈/서비스/리포트, 원본 장표 PNG/PPTX, 기존 로컬 비교자료가 모두 들어 있다.
웹·모델·로그인이 필요 없는 로컬 파일 묶음이다. 브라우저가 파일 기능을 제한하면 README의
로컬 HTTP 실행 방법을 사용한다. 실제 Mac/iPhone에서의 열람은 별도 확인해야 한다.

공개 사이트의 예시 수치를 실제 모델 결과라고 발표하지 않는다.
개발 시연 경기(컵스 @ 파드리스, 849843)와 평가 경기(필리스 @ 브레이브스, 849845;
레이스 @ 필리스, 823407)를 구분한다.

## 발표 순서 — 시간은 목표, 실제 계측 아님

| 목표 구간 | 조작 | 핵심 |
|---|---|---|
| 0:00–0:20 | 홈 → 미트 위치 보기 | 우리 목표와 내가 맡은 영상 관측 모듈 |
| 0:20–0:35 | 분석 서비스에서 시나리오 하나만 | 최종 흐름의 예시 수치임을 명시 |
| 0:35–0:55 | 실제 관측 리포트 849843:1:3 공개 → 849843:2:5 기권 | 저장 39구 / 좌표 27 / 기권 12 |
| 0:55–1:40 | 기존 CV 요약 PNG → 대표 849845:10:4 | 평가 86/58/28, 범례, 확정 문구 |
| 1:40–2:00 | 대표 그림 유지 | 확인된 범위와 다음 검증 |

이 리포트의 공개 버튼은 수동 표시 조작이며 실제 영상 공개 시각에 연동된 것이 아니다.
기존 합의는 실제 투구 공개 후 x만 표시하는 것이다. 홈의 정지 장면 미트 표시는 저장 관측
설명용이며 실시간 사전 추정, 실제 서비스 공개 시점 검증으로 취급하지 않는다.

## 읽을 대사

저희는 한 공의 추천과 실제 결과를 비교해 경기를 더 쉽게 이해하도록 돕는 서비스를 만들고 있습니다.
저는 영상에서 포수 미트를 읽고 좌표로 전달하는 CV 부분을 맡았습니다.
지금 점은 이 정지 장면에서 판독한 저장 결과입니다.

이 화면은 최종 사용자 흐름입니다. 추천·확률·투수·타자·교체 평가는 연결할 자리를 예시로
구현했습니다. 여기의 예시 수치와 지금부터 보여드릴 실제 CV 결과는 구분합니다.

시연 자료는 2026년 9월 29일 컵스와 파드리스 경기입니다. 사전 처리한 39구 중 27구에
미트 좌표가 있고, 12구는 판독을 보류했습니다. 확정한 시연 범위는 실제 투구 공개 후
가로 위치만 표시하는 것입니다. 이 자체 리포트의 공개 버튼은 수동 표시 전환입니다.

평가는 별도 두 경기에서 했습니다. 전체 86장 중 AI 출력은 58장, 기권은 28장입니다.
이 그림은 필리스와 브레이브스 경기의 크리스 세일 대 브라이슨 스톳 사례입니다.
중앙값에 가장 가까운 대표 사례이며, 초록 원이 AI, 빨간 십자가 사람 표시입니다.

> 평가 2경기에서 AI와 사람이 모두 표시한 58구의 미트 점 차이 중앙값은 2.5px입니다.
> 같은 변환 기준의 좌표 차이는 중앙값 약 1.1인치이며, 물리 정확도나 투수 의도를 검증한 값은 아닙니다.

현재 확인한 것은 미트 판독과 사람 표시의 일치 정도입니다. 포수의 요구 위치나 투수의
제구 실책을 판정한 결과는 아닙니다. 다음은 연속 한 타석에서 실제 판독과 처리 시간을
확인하고, 새 영상과 독립 라벨러로 검증하는 것입니다.

## 질문 대응

- **투수의 실투를 판정하나요?** 미트 관측부터 준비한 단계다. 그 미트가 실제 요구인지,
  공과 같은 기준으로 비교할 수 있는지 추가 검증해야 한다. 현재 차이를 제구 오차로 계산하지 않는다.
- **1.1인치가 실제 정확도인가요?** 동일 변환 기준에서 58구의 AI·사람 x·z 좌표 거리를
  비교한 중앙값이다. 물리 정확도, 가로 오차, 대표 한 구의 오차가 아니다.
- **다른 비교 그림도 있나요?** 같은 비교 페이지에서 성공·실패·FOX 예시를 펼친다.
  본 설명에는 대표 한 개만 사용하고 좋은 사례만으로 일반 성능을 주장하지 않는다.
- **모델 연결은 어디까지 됐나요?** 우리 파일 수신 도구의 구조·연결 검사는 준비됐다.
  실제 응답은 아직 미수신이다. 합성 테스트는 실제 모델/실경기 결과가 아니다.
- **팀원과 역할이 겹치나요?** 팀원은 모델·확률·정책·실제 관전 서비스를 맡는다.
  나는 미트 판독·좌표·검증 및 독립 설명용 사이트와 수신 점검을 준비했다.
- **자동·실시간인가요?** 지금은 저장 자료다. 연속 영상의 실제 판독 지연과 사전 가용률은
  아직 검증하지 않았다. 기존 세 프레임 호출을 전체 자동 관측으로 설명하지 않는다.

브라우저 보안 설정을 해제하거나 실제 모델 API를 급히 변경할 필요가 없다.

## 배포·보존 범위

이 묶음은 지정 팀원에게 비공개 파일로 전달하거나 현장에서 여는 용도다.
comparison/의 기존 비공개 그림 취급은 유지한다. 홈페이지 영상 공개 승인만으로
이 묶음 전체를 공개 업로드한 것으로 확대하지 않는다. 이 작업에서 팀원에게 보내지 않았다.
모델 체크포인트·사람 원본 라벨·private 세션·전체 영상·API 인증정보는 포함하지 않는다.

기존 M3·JSONL·PPTX·PNG·비교 HTML은 수정하지 않았다. 파일별 해시는 bundle_manifest.json을
참조한다. 원본 파일 바이트 검사이며 모델 진위/실시간 성능 인증은 아니다.
재생성·검증 명령은 저장소 `docs/PITCH_STUDIO_OFFLINE_BUNDLE.md`에 있다.
