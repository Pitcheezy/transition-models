## 로컬 화면

선택한 경기의 타석과 투구를 고르고 구종 후보를 본 뒤 **실제 결과 공개**를 누른다.
첫 타석 `849843:1`은 3구이며 셋업은 첫 두 구에 없고 3구에만 있다.
공개 전에는 실제 결과·도착점·미트 x를 화면에 만들지 않는다.
다른 투구·타석·파일로 이동하거나 공개를 초기화하면 다시 숨긴다.

후보 위치와 실제 공은 ft 단위 x/z 평면에 표시한다. 미트는 높이가 없는 **별도 가로 축**에 표시한다.
세 값을 연결해 제구 오차·투수 의도·타자 책임을 계산하지 않는다.
점수·카운트는 선택한 투구의 `situation_before`를 사용하고 최종 경기 점수나 타석 결과를 미리 표시하지 않는다.
검토 파일에는 이미 사후 자료가 있으므로 화면 숨김은 보안 기능이나 투구 전 추론의 증명이 아니다.

다음 명령의 입력 경로는 비공개 수신 폴더다. 출력 폴더는 새 이름을 써야 한다.

```text
uv run --frozen python scripts/inspect_service_game.py --input outputs/service_review_received_20261009/service-game-849843.json --source-kind provided_export --profile teammate_export_20261009_v1
uv run --frozen python scripts/build_service_review.py --input outputs/service_review_received_20261009/service-game-849843.json --source-kind provided_export --out-dir outputs/service_review_preview_20261009_v2
python -m http.server 8794 --bind 127.0.0.1 --directory outputs/service_review_preview_20261009_v2
```

같은 컴퓨터에서 `http://127.0.0.1:8794/`을 연다. 다른 컴퓨터의 localhost에는 연결되지 않는다.
생성된 폴더는 내부 검토용이며 공개 배포 대상이 아니다. 새 웹 코드는 원문을 내장하지 않는다.

## 해석과 남은 조건

- 추천은 `asof_replay`다. 전달자 기록상 경기 종료 후 약 4시간 뒤 생성된 자료이며 실시간 사전 캡처가 아니다.
- `feed.as_of`는 이 아카이브 응답 생성 시각이다. 피드 수신 지연으로 해석하지 않는다.
- 추천 제공률과 모델 정확도·승리확률 개선은 별개다. 스트라이크·파울·안타 사건확률은 제공되지 않았다.
- 공급자는 ready 246구 중 fallback 10구와 실제 투구 의존 거부에서 시작한 3구를 보고했다.
  근거 watch 파일은 ZIP에 없고 응답에도 구분 필드가 없다. 이 계보는 독립 확인하지 않았다.
  첫 타석은 해당 범주 밖이라고 보고됐지만 이것이 누출 없음이나 정책 효과를 증명하지 않는다.
- 미트는 응답 밖 계약에 미검토 AI 추정으로 설명돼 있다. 사람 정답·실제 투수 의도로 표시하지 않는다.
- missing은 실제 0건이다. 합성 회귀 검사를 실제 수신 사례로 세지 않는다.
- 런타임 커밋·가중치 버전·정확한 학습 cutoff·수신 기기의 서버 연결·라이브 경로는 미확인이다.
- I-run1(서비스 자체의 독립 실행), I-release1(실기기·지연·공개 배포 검증), CV-6/A-y/CV-7은 별도다.
