# 브라우저 파일 선택 검수와 투구 식별자 수정 — 2026-10-10

I-service4 완료. `bbf56f7`의 검토 화면에서 잘못된 보고서의 투구 번호와 영상이 어긋나는 오류를
실제 Chrome으로 재현하고 수정했다. 선점 `9b400cc`; 구현은 이 기록과 같은 커밋이다.
팀원 저장소·공개 Site는 조회하거나 변경하지 않았다. 원본 응답·영상·M3·사람 판독은 보존했다.

## 발견한 문제와 수정

정상 보고서의 사본에서 첫 행의 `pitch_number`만 99로 바꾸면,
화면은 ‘1회 초 · 99번째 투구’를 표시하면서 `849843:1:1` 영상을 연결했다.
서버 실행기는 식별자를 검사했지만, 브라우저의 ‘보고서 열기’는 해당 서버 검사를 거치지 않았다.

브라우저도 아래 두 식별자가 경기·타석·투구 번호와 정확히 일치해야 보고서를 수용하도록 했다.

- `pa_key = game_pk:at_bat_number`
- `key = game_pk:at_bat_number:pitch_number`

게임 번호, 타석/투구 번호, 각 키, 0을 붙인 키, 다른 경기의 타석 키를 바꾸는 7개 검사는
수정 전 모두 실패하고 수정 후 모두 통과했다. 기존 비동기 테스트의 합성 경기 변경도 키와 일치시켰다.
이는 내부 식별 정합성 검사다. 원문 해시를 임의 복사한 파일의 출처를 인증하거나 내용 진위를 보증하지 않는다.

## 실제 브라우저 검사

전용 CUA와 node 도구는 `trusted Node process exited unexpectedly`로 시작하지 못했다.
기존 설치된 Chrome 154.0.8037.58을 Playwright로 별도 실행했다. 결과는 **21개 시나리오 통과**다.
화면의 파일 버튼을 클릭해 발생한 실제 `filechooser` 이벤트에 로컬 파일을 넣고 DOM과 영상 상태를 확인했다.
운영체제 파일 대화상자를 직접 조작하거나 사람이 사용한 결과로 기록하지 않는다.

- 공개 후 잘못된 JSON·스키마·프로필·UTF-8·5 MiB 초과 파일 선택: 이전 결과·좌표·영상 제거, 오류 표시.
- 식별자 불일치 7종: 파일 거부. 정상 보고서로 다시 열면 숨김 상태로 복구.
- 같은 파일 재선택: 공개 상태 초기화. 빈 파일 선택: 기존 상태 유지(실제 OS 취소 버튼 검증 아님).
- 원문 SHA가 다른 보고서: 영상 연결 거부, 추천 검토·수동 결과 공개는 유지.
- 재생 중 잘못된 파일 선택: 영상과 결과 제거.
- 3구 실제 재생 종료: 실제 구종·97.6 mph·미트 x -0.05 ft 공개. 다른 투구 선택 시 다시 숨김.
- 폭 390px 화면: 가로 넘침 없음. 문서 폭390px, 영상 폭324px.
- 외부 요청0, GET/HEAD 이외 요청0, 미처리 페이지 오류0. 로컬 파일을 업로드하지 않았다.

데스크톱 공개 전/후와 모바일 크기 공개 후 캡처를 Git 제외 폴더
`outputs/service_review_browser_20261010_v1/`에 저장했다. 공개 후 데스크톱/모바일 캡처를 직접 보아
추천·실제 위치·별도 가로 미트 축·영상·주의 문구 배치를 확인했다. MLB 이미지이므로 공개 문서에는 넣지 않는다.

## 수정판 실행팩

**이후 전달에는 `outputs/service_review_video_20261010_v2.zip`을 사용한다.**
v1 ZIP은 보존했으며 수정판은 검토 JS와 영수증만 다르다. 나머지14파일, 정규화 보고서와 3개 영상은 같다.

- ZIP: 13,570,913bytes / SHA256 `31629dc1867b34469d8b7aa624e7eb58df5bc46cfc169282c2e021531b975d49`
- CRC 정상,16파일 실제 압축 해제본과 원본 바이트 일치.
- 한글·공백 경로로 옮겨 다른 작업 폴더의 격리 Python으로 `launch_review.py --check` 통과.
- Windows `START_WINDOWS.cmd`, Mac `START_MAC.command`; Python3.10 이상 필요.
- 명령 대안: Windows `py -3 launch_review.py --open`, Mac `python3 launch_review.py --open`.
- 직접 실행한 컴퓨터에서만 주소가 열린다. 다른 기기에서는 팩을 옮겨 실행한다.
