## 사용자에게 달라지는 것

- 키보드 Enter/Space로 2구를 고르면 화면이 다시 그려져도 2구 버튼에 포커스가 남는다.
  이전에는 BODY로 사라져 다음 Tab이 1구로 돌아갔다. 다른 컨트롤의 포커스는 옮기지 않는다.
- CLI 보고서는 UTF-8 원문을 간결하게 저장하고, 쓰기 전에 화면과 같은 5 MiB 상한을 확인한다.
  합성 1,500구 입력 3,369,265bytes에서 기존 출력 6,773,500bytes는 화면에서 열리지 않았다.
  수정 후 같은 내용의 출력은 3,519,626bytes다. 여전히 상한을 넘으면 파일을 만들지 않고 거절한다.
- 화면이 feet/mph/구종 선택 비중/포수 시점 x라는 정규화 단위 선언을 확인한다.
  meters를 ft로 잘못 설명하거나, 후보 비중 합계가 100%를 넘거나, 같은 구종을 중복 표시하는
  보고서를 거절한다. 부분 비중과 null을 채우거나 다시 합계 1로 만들지 않는다.

화면 입력의 단위 계약을 강화한 것이다. 새 사건확률·높이 추정·정책 효과를 계산하지 않는다.
현재 정상 262구 보고서는 기존 v4와 바이트가 동일하다.
원문 SHA256: `df606a11c6db465c054252ef8d331aeb23aa21565b4960bd586f3dcf8f62f6b7`.
정규화 SHA256: `154d9cd1cb166552db5975137e2ba431b9ab48f94fcfa6bdd05304f645427c80`.

## 배포·이관 범위

이 변경은 로컬 검토 화면이다. 공개 Site와 팀원 저장소/API를 변경하지 않았다.
수정 소스와 화면의 v5 전달팩을 완료했다. [파일별 SHA·압축 해제 검사](handoff/delivery_v5.json)를 기록했다.
기존 v1~v4, 원본 영상·응답·라벨을 보존한다. 사용자가 보류한 A-y는 재개하지 않는다.
I-0/I-run1/I-release1, CV-6/CV-7 및 의도 정의 등 외부 근거가 필요한 항목은 미완료다.

새 영상 검토팩 v5는 16파일, 13,571,942bytes,
SHA256 `51af1e8861ac5e7294b185acb3f525fa2b421765152ff2a65abdbb2f92317546`다.
CRC·실제 압축 해제·원본과 16파일 동일·격리 실행기 검사를 통과했다.
v4 대비 `review.js`, `receipt.json`만 바뀌었고, 실제 3클립은 재생 후 끝부분으로 탐색하여

직접 캡처를 확인했고 오류·외부 요청은 없었다. 이 기록은 새 사용자 실기기 확인이 아니다.
