# SITE-audit1 — 교수 시연 전 페이지/동선 점검

사용자 캡처는 `/receiver` 상세 분석이었다. 맞춤 재생바·공 도착 시점 표시는 `/watch` 관전 화면에
있지만 기존 홈/경기 링크 여러 곳이 상세 분석으로 향해 기능이 없는 것처럼 보였다.
같은 투구를 유지하며 화면을 이동하고, 두 화면의 역할을 분명히 했다.

## 수정

- 주요 관전 진입을 watch로 통일. receiver는 명시적인 상세 분석으로 유지.
- 상세 분석→관전 링크가 선택한 공을 유지하도록 수정. 보관본/가져온 파일을 같은 경기로 오인하지 않게 숨김.
- 상세 분석에서 되감기·재생·디코더 오류가 실제 결과/점/기록 존을 남기던 문제 수정.
- watch에 경기 전체 투구 선택바를 추가. 끄는 동안은 선택 미리보기, 놓을 때 선택 공의0초로 이동하며 자동 재생하지 않음.
- 기존 초 단위 재생바는 현재 클립용으로 유지. 두 바가 연속 중계의 전체 시간표인 것처럼 표시하지 않음.
- 공개 전/기록 미연결 때 높이1.5–3.5ft·17인치 폭의 점선 참고 존. 타자 기록이 아닌 예시라고 표시.
  공개된 기록 존은 흰 실선9분할로 대체. 좌표로 심판 판정/제구 오차를 계산하지 않음.
- 영상 오류의 존재하지 않는 결과 버튼 안내를 현재 공 상세 분석 링크로 교체.
- 이용 안내에 첫 타석→다른 타석→상세·모델 근거 시연 순서 정리.

## 화요일 시연 권장 순서

1. 홈에서 경기 관전. 첫 타석1구를 재생하며 추천은 먼저, 실제 위치는 확인된 도착 구간 뒤에 나타남을 설명.
2. 현재 타석 이어보기로3구 확인. 판정·최종 결과는 각 클립 종료 뒤 공개됨.
3. 경기 탐색바/타석 선택으로 다른 공 이동. 이 공들은 도착 시점 미확인이라 종료 기준임을 설명.
4. 상세 분석에서 실제 위치·추천 근사·미트 관측을 구별하고, 이용 안내의 모델 근거 확인.

현재 정확한 설명은 ‘한 경기262구의 기록,261개 개별 영상,246구의 받은 추천을 연결한 저장 경기 관전’이다.
연속 중계 파일·전경기 정밀 포구동기화·라이브 추론 완료가 아니다. 실제 점은 플레이트 통과 좌표이며
포수가 잡은 좌표가 아니다. 모델 선택 비중은 스트라이크/안타 사건확률이 아니다.
