## 완료한 사용자 기능

849843의 기존 PC·모바일 재생 화면에서 71타석·262구를 탐색하며, **261구의 공식 영상**을
같은 투구의 저장 추천·실제 결과와 함께 본다. 클립 종료 시 해당 투구의 결과를 공개한다.
다음 투구는 사용자가 선택하고, 타석/투구 전환 시 이전 영상·결과·좌표를 초기화한다.
영상 오류나 영상 제외 시에도 ‘현재 투구 결과 공개’로 기존 기록을 비교할 수 있다.

- 추천246구·미지원16구는 기존 받은 응답 그대로다. 새 모델 실행이나 새 추천 생성은 없다.
- 기존 첫3구는 사이트의 저장 영상, 나머지258구는 등록부에서 확인한 MLB 공식 서버 URL을 사용한다.
  선택한 영상만 불러온다. 원격 서버 연결이 끊기면 이258구는 재생할 수 없지만 결과 비교는 유지한다.
- `849843:69:2`는 받은 결과 FC(커터), 영상 등록부 SL(슬라이더)로 달라 영상 연결을 제외했다.
  어느 원본도 수정하지 않았다. 화면은 구종 불일치 이유를 표시하고, 추천/결과는 계속 제공한다.
- 전체 경기에서 기존 첫타석3구의 별도 미트 정지 프레임을 섞지 않는다. 받은 가로 추정만 결과 뒤 표시한다.
- 홈·경기·안내·서비스·재생 페이지의 영상 범위를 함께 갱신했다. 기존 디자인과 첫타석 모드는 보존했다.

여기서 동기화는 **같은 투구 ID의 영상·저장 추천·결과를 묶고 클립 종료 뒤 결과를 공개하는 것**이다.
정확한 릴리스/포구 시각 동기화, 연속 중계, 전체 프레임의 미트 검증, 실시간 추론이 아니다.
리플레이가 포함된 클립은 마지막까지 재생한 뒤 공개된다. 결과를 먼저 보고 싶으면 수동 공개도 가능하다.
