# SITE-watch3 — 관전 중심 여섯 기능

기존 홈 디자인을 보존하면서 `/watch?game=849843`에 사용자 승인 여섯 기능을 연결했다.
제품 고정 커밋은 `040ca75`이며 우리 PR85의 작업 브랜치, main 통합, Sites 공개는 구분한다.

## 관람자가 쓰는 기능

1. PC는 큰 영상 옆에 추천 순위·위치·실제 결과를 배치한다. 좁은 화면은 영상→비교→투구 순서→통계로 이어진다. 긴 좌표 설명은 접는다.
2. 같은 타석의 투구 리본을 누르면 정확한 투구 ID로 이동한다. 이전 공은 기록을 표시하고 현재 공은 종료 후, 이후 공은 숨긴다.
3. 이닝·볼카운트·아웃·주자 상황을 한 줄로 표시한다. 근거 없는 전술·의도 설명을 생성하지 않는다.
4. 현재 경기의 투수·타자·볼카운트를 함께 검색한다. 결과는 12개씩 나누고 투구 전 정보만 보여준다. 검색 변경은 재생을 멈추며 자동으로 다른 공을 선택하지 않는다. 이어보기는 검색 결과 목록이 아니라 선택 공부터 실제 타석·경기 순서다.
5. 선택한 공 이전에 같은 투수가 이 경기에서 던진 공만 구종별 집계한다. 전체 표본 수와 구속 기록 수를 분리하고 평균은 구속이 있는 기록으로 계산한다. 추천 비중·시즌 통계와 구분한다.
6. 추천 점·실제 공 점을 각각 켜고 끈다. 미트 가로 관측은 선택 시 별도 축으로 보여주며 클립 종료 뒤에만 공개한다. 레이어 전환은 영상 재생이나 현재 공을 바꾸지 않는다.

## 자료와 공개 시점

- 기존 경기 849843의 71타석·262구, 추천246/미지원16, 영상261구를 그대로 사용했다. 새 모델 추론·자료 수정 없음.
- 첫 타석 3구의 확인된 도착 구간 상한에는 실제 위치만 표시한다. 구종·판정·타구 결과·미트 관측은 클립 종료 후 공개한다. 다른 연결258클립은 위치도 종료 기준이다.
- 결과를 되감거나 공을 바꾸면 이전 점·결과·미트가 사라진다. 주소 실패는 리본·통계·필터 결과도 정리한다.
- 미트는 받은 응답의 미검토 셋업 가로 추정이다. 현재 영상의 프레임과 대응·높이·투수 의도는 검증되지 않았다. 근거 이미지를 임의 결합하거나 존 위에 높이를 채워 넣지 않았다. 판독 기권과 미제공을 구분한다.
- 표시 축 밖의 미트값은 끝점으로 이동시키지 않고 텍스트만 남긴다. 실제 자료에는 이 사례가 없어 해당 DOM 사례는 미측정이다.
- 전 경기의 정확한 포구 시점, 연속 중계 시간표, 실시간 추천, 제구 오차 계산 완료를 뜻하지 않는다.
