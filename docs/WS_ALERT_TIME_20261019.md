## 재현과 수정

- 안전정수지만 Date 범위 밖인 사건 시각은 분류를 통과한 뒤 `toISOString()`에서 RangeError를 냈다. 잘못된 사건 뒤 정상 사건을 넣어도 모의 전달 0건이었다. 날짜로 표시할 값에 0~8,640,000,000,000,000ms 범위를 적용하여 잘못된 개별 사건만 건너뛰고 정상 사건은 양쪽에 전달한다.
- 저장된 `2026-02-30T00:00:00.000Z`가 3월 2일로 바뀌었다. 저장된 관측 시각·재분류 원인 시각을 ISO 왕복 비교해 잘못된 원문을 거부한다. 기존 도구가 생성하는 UTC 밀리초 정밀도·확장 연도와 v1/v2/v3 상태를 보존한다. 사람이 고친 비정규 시각 문자열을 자동 보정하지 않는다.
- 최신 감시 보고의 표현 불가능한 시각은 기존의 잘못된 보고 처리처럼 재분류 근거에서 제외한다. 카운터·산술용 실행 시계의 안전정수 상한은 바꾸지 않는다.
- 현재 incident 오류는 CLI의 기존 검증 경로에서 잠금 전에 거부한다. 저장 상태 오류는 잠금 안에서 읽고 검사하므로 잠금 생성 자체를 막는 것은 아니다. 모의 전달·상태 교체 전 거부하며 잠금은 정리한다. 원본 상태와 다른 소유자의 잠금 보존을 검사했다.
