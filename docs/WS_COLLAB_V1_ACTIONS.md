## 본인이 직접 할 일과 AI에게 맡길 일

- **지금 사용자에게 급히 요구할 입력은 없다.** 이미 보낸 ZIP을 다시 만들거나 보내지 않는다.
  최신21,561bytes 호스트 증거팩은 사용자 발송 보고만 있고 상대 수신/검증은 미확인이다. 과거 반환팩v2 수신 회신과 구별한다.
- **형의 새 고정본을 받으면:** 이 채팅에 비공개로 첨부한다. 해시·핀·검토 자료 대조, 로컬 검증과 회신 초안은 AI가 한다.
- **그다음 사람끼리 정할 것:** 가능한 시험 시간과 즉시 연락할 채널/응답 가능 시간, 참여자·중단/회수 담당을 확정한다.
  이들은 일정/접근/실제 실행 결정이어서 AI가 추정하여 합의할 수 없다. 구체적인 시험안이 준비되면 한 번에 확인한다.
- **실제 연결 직전:** 승인 화면의 대상·변경 범위·회수 방법을 보고 해당 창 GO를 정한다.
  자격값/연락처는 비공개로 전달하고 공개 이슈나 채팅에 비밀을 붙이지 않는다. 계정 관리 토큰은 Song에게 보내지 않는다.
- **운영 전에:** 본인/초대자/일반 공개 중 접근 범위, 안내 문구·Song 조작 권한·복구 책임, 실제 알림을 양측이 정한다.
  이메일 제공자·발송·비용이나 일반 공개를 지금 자동 선택하지 않는다. 전시 용량/요금제 판단은11월이다.

새 파일이 오기 전에는 **우리 코드의 재현 가능한 고장 또는 인계/증거 누락만** 독립 단위로 처리한다.
새 기능·같은 시험 반복으로 대기를 지우지 않는다. PR63 config 검사·PR64 실제 증거·PR65 로컬 준비는
서로 다른 변경이며, main 통합/충돌 해소와 Cloudflare 재배포도 별개다.
A-y/F-4i 보류, CV-6 사람 검토, CV-7 새 영상/독립 라벨, I-device2 실기기 등은 별도 잔여이며
