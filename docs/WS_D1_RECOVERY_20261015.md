# WS-recovery1 — 합성 D1 복구 후 점검

기준 main `d36d0893862c6ce2c5381327ce233cac7029b21e`, 선점 `ce5f524`.
사용자가 팀원 응답 없이 우리 담당 작업을 계속 요청해 기존 복구 절차의 미검증 부분을 보완했다.

[실행·범위](../ops/public-host/D1_RECOVERY.md). 실제 SQLite 복사·읽기 전용 검사 10개 사례와
CLI 입력/기존 출력 보존 검사 4개를 통과했다. 문법 검사도 통과했다.
고정 코드의 다른 모델 검토와 최종 회귀 결과는 완료 기록에서 갱신한다.

핵심 결과: 만료 기록 정리만으로 과거 백업의 일일 저장 상한 되감김이 해결되지 않는다.
사고 전 집계 근거가 없으면 미확인으로 남기며 자동 수집 재개를 승인하지 않는다.
합성 사례의 수치는 실제 이용량·복구 성능이 아니다. 팀원 코드·실계정·배포·실제 영상 변경 없음.
