# WS-human1 — 실제 연결을 시작하기 위한 사람 결정서

2026-10-15, 근거 코드 `c07dc942030e5ec4f100f638d572239524cd327e`.
**확인된 선택은 본인 Cloudflare 계정·본인 시험 접속이다. 예산·수집 여부는 미정이다.** 빈칸·추천안·침묵을 승인으로 처리하지 않는다.
이 문서는 결정의 기록 장소이며 계정 생성·비용·접근 변경·배포를 실행하지 않는다.
비밀, 계정 식별값, 서비스 주소, 연락처는 이 파일이나 공개 이슈에 넣지 않는다. 공개 기록에는 역할·결정 여부·범위만 남긴다.

## 가장 먼저 답할 네 항목

- **계정과 담당:** 사용할 호스팅 계정의 소유 역할, 실제 설정을 할 사람. 예: 본인 소유 Cloudflare 계정 / 본인. 기존 도메인 구매를 이 신규 호스팅 계정·비용 승인으로 간주하지 않는다.
- **첫 접속 범위:** 우리 담당자만 / 우리와 Song / 정한 초대 인원 중 선택. 별도 비공개 시험 환경부터 할지 정한다. 일반 공개나 기존 사이트 교체는 별도 결정이다.
- **비용:** 비용 발생 불가 또는 허용할 월간 USD 상한과 재확인 기준. 예상 비용은 선택한 부하·현행 가격을 다시 확인해 제시하며, 상한 승인을 자동 과금 차단 기능으로 설명하지 않는다.
- **이용 기록·피드백:** 각각 OFF 유지 또는 ON 준비. OFF를 선택하면 이번 비공개 시험에는 수집하지 않고, 수집 동의·보관일 결정은 활성화 전에 한다. OFF도 공개 범위·비용·실경기 연결 승인과 별개다.

답변용 형식(값은 예시로 미리 채우지 않음):

```text
계정 소유 역할 / 설정 담당:
첫 시험 접속 대상 / 기존 사이트와 분리 여부:
월간 USD 예산 / 재확인할 비용 기준:
이용 기록 OFF 또는 ON 준비 / 피드백 OFF 또는 ON 준비:
```

이 네 답이 오면 **승인된 범위의 실제 계정 준비 계획·고정 배포 도구/버전·설정 후보**를 구체화할 수 있다.
가격과 계정 권한을 확인하기 전에 비용이나 자원을 자동 만들지 않는다. 실제 배포할 고정 후보와 예상 비용·권한 변경을 검토할 수 있게 준비한 다음,
사용자가 승인한 실행 범위를 확인한다. 이 문서 작성만으로 배포 승인이 생기지 않는다.

## 계정 없이 먼저 풀 수 있는 한 항목

- **실제 알림 채널 종류:** 사용할 채널 이름을 정하면 그 채널의 transport 구현·모의 검사를 준비할 수 있다. 사용자는 이메일을 희망한다고 답했다. 발송 제공자·인증·실제 발송 승인은 미정이다.
  채널 선택은 실제 발송 승인이나 수신자 확인이 아니다. 연락처/토큰은 비공개이며 양쪽 수신·응답 시간은 따로 확인한다.

```text
알림 채널 종류:
양쪽 수신/응답 시간 합의 여부:
```

이메일 후보로 Cloudflare Email Service를 조사했다(10/15 공식 문서). 인증된 수신 주소로 보내는 메일은 모든 플랜에서 무료이며 Worker 실행 요금은 별도다.
실제 계정 기능·발송 도메인 DNS·수신 주소 인증은 확인하지 않았고 설정하지 않았다. Gmail은 수신 주소로 쓰므로 Gmail 비밀번호를 저장하거나 받지 않는다.
이 후보 조사만으로 제공자를 최종 선택하거나 도메인 설정·메일 발송을 승인하지 않는다.
[공식 요금](https://developers.cloudflare.com/email-service/platform/pricing/) · [발송 설정 조건](https://developers.cloudflare.com/email-service/get-started/send-emails/).

## 공개·수집·실경기 전에 별도로 결정할 것

- **10/20까지 연락과 응답 시간:** 우리/Song 담당자의 비공개 연락 수단과 시간대. 우리 쪽 예약 등록은 Song의 일일 확인 수행 근거가 아니다.
- **수집을 켤 경우:** 이용 기록과 피드백 각각의 동의 안내·보관일·일별 저장 상한·열람/삭제 담당. 원시 자료·접속 주소는 공개 이슈에 올리지 않는다.
- **긴급 안내와 복구:** 양쪽 담당 사람이 즉시 안내로 바꿀 수 있다는 원칙은 이미 합의됐다. 남은 것은 실제 운영자 권한·비공개 조작 경로·문구·다시 공개할 담당이다. AI의 실제 조작은 승인된 위임 범위만 따른다.
- **실경기/기존 사이트:** 연결할 경기·시간·범위, 기존 Sites/DNS를 바꿀지, 실제 운영 재개 승인. 비공개 시험을 일반 공개로 확대하지 않는다.
- **발신:** [최신 COLLAB-001 회신](mail_drafts/COLLAB-001-reply-draft-20261015.md)을 우리 mail #18에 한 번 게시할지 결정한다. 이 승인은 다른 mail 생성·자동 경기 보고·추가 메시지까지 포함하지 않는다.
- **10/21 이후:** 기능 추가 대신 고장 수리만 한다. 날짜가 도래했다고 출시 승인으로 바꾸지 않는다.

## 답이 와도 별도로 남는 전달물과 검사

- Song 후속: `unsupported` 예시, 후보 probability/target 스키마, 최종 고정 공개 빌드·발행기/업로더·발행 규칙. 실제 수신·SHA 검사를 해야 해제한다.
- 계정 준비 뒤: 제한된 업로드 경로, 실제 CDN/삭제/충돌/복구, 상시 감시와 양쪽 실제 알림 수신. 로컬 합성 검사를 실제 성공으로 바꾸지 않는다.
- 실제 Mac/Safari/iPhone, 실제 피드 지연·다음 투구 전 표시율. 기존 영상 검토팩의 Mac 전달·확인은 별도다.

- CV-5a/CV-6/CV-7의 별도 조건, 사용자 보류 A-y/F-4i를 운영 연결의 새 선행 조건으로 만들지 않는다.

## 결정 기록과 재개 방법

결정마다 `항목 / 사람이 정한 값 / 승인 범위 / 확인 시각 / 대화 또는 이슈 근거 / 남은 조건`을 남긴다.
비공개 결정 근거는 공개 파일에 복사하지 않고 승인 여부만 기록한다. 현재 사용자 답변(2026-10-15, 이 채팅)에 따른 비밀 없는 기록은 다음과 같다.

- 계정 소유 역할: 본인 Cloudflare 계정. 실제 계정·상품·권한 조회는 아직 하지 않았다.
- 시험 접속 대상: 본인. 기존 공개 사이트 변경·일반 공개·Song 접근까지 승인한 것이 아니다.
- 월 예산·수집/피드백: 설명 요청, 결정 대기.
- 알림: 이메일 희망, 개인 수신 정보는 공개 파일에 기록하지 않는다. 발송 제공자·인증·실제 발송·Song 수신자는 미정이다.
- COLLAB-001 회신 게시·실제 배포: 승인 대기.

이용 기록은 동의한 브라우저 세션 수와 화면 활성 시간이며 고유 사람 수가 아니다. 피드백은 도움됨/불명확/문제 있음과 선택 범주이며 자유문·연락처를 받지 않는다. 자세한 저장·동의·보관 범위는 [TELEMETRY](../ops/public-host/TELEMETRY.md)를 따른다.

완성된 공개 빌드와 고정 출처가 오면 [패키지 검사](../ops/public-host/RELEASE.md) → [설정 검사](../ops/public-host/CONFIG_CHECK.md)를 사용한다.
두 검사는 계정/배포 기능이 없고 `deployable=false`다. [운영 절차](../ops/public-host/RUNBOOK.md)의 실제 Wrangler 버전·경로는 아직 미고정이다.
지금 임의 배포 명령을 채워 실행하지 않는다. 선택한 다음 작업에 필요한 결정과 입력이 준비되면 짧은 다음 작업을 우리 board에 먼저 등록한다. 알림 채널의 모의 구현이나 계정 준비 계획을 위해 모든 Song 전달물을 기다리지는 않는다.

- **추가 비용 $0:** 무료 구간에서 가능한지 확인한다. CPU/요청 한도로 시험이 제한될 수 있고 무료 보장을 하지 않는다.
