# WS-report2 — 오프라인 이용 기록 내보내기

기준 main `fe6194670ceaa4105d28ec65da97d08730a1078c`, 선점 `6197660`.
우리 이용 기록 담당 범위의 독립 작업이다. Song 코드·프로세스·배포에는 접근하거나 변경하지 않았다.

## 구현

- [도구·실행·제약](../ops/public-host/EXPORT.md): 닫힌 SQLite 스냅샷 → 기존 summarizeTelemetry SQL → 비공개 집계 포장 JSON.
- 읽기 전용 연결·하나의 읽기 트랜잭션·전후 SHA/파일 상태 대조, sidecar/WAL/뷰/잘못된 스키마/값/덮어쓰기 거부.
- 원본 ID·원본 경로 미출력, UTC 날짜/현재 시각 만료 기준, coverage=unverified.
- 실제 로컬 D1과 같은 합성 자료를 넣어 집계 일치를 확인했다. 원본 파일·폴더 불변도 확인했다.
- 추가 검토에서 Mac의 대소문자 구분 없는 경로, 복합 PK·NULL ID로 세션이 부풀려질 수 있는 경우를 보강했다.
- 기존 retention 테스트는 고정 10/12 합성 시계와 실제 HTTP 시계가 섞여 10/15부터 1행이 남았다.
  삭제 검사 시각을 두 시계 모두의 만료 이후로 정해 날짜 경과에 의한 실패를 수정했다. 서비스 수집/삭제 코드는 변경하지 않았다.

## 남은 연결

자동 승인 검토가 `report.mjs` 코드 변경을 거절했다. 최신 사용자 실행 지시와 선점 근거를 제시한 재심도 거절했다.
[검토 가능한 변경안](WS_REPORT2_REVIEW_PROPOSAL.md)을 작성하고 사용자 재승인을 요청했다.
거절된 코드는 적용하지 않았다. 포장 파일의 직접 보고서 입력은 거부된다. 내부 요약만 추출해 이 보호를 없애면 안 된다.
따라서 WS-report2 전체 합격 기준의 보고서 연결은 아직 미완료다.

## 검사와 검토

내보내기 11검사, 전체 운영 Node 197검사, 체크리스트 8검사를 통과했다. Python 하위 프로세스 한글 디코딩 경고는 PYTHONUTF8=1로 재검사한다. 다른 모델 검토·최종 커밋·해시는 종료 기록에 추가한다.
증거는 합성 자료와 로컬 D1이며 실제 Cloudflare 취득·실경기 이용량·큰 DB 성능은 미측정이다.
