# WS-report2 — 오프라인 이용 기록 내보내기와 보고서 연결

기준 main `fe6194670ceaa4105d28ec65da97d08730a1078c`, 선점 `6197660`.
우리 이용 기록 담당 범위의 독립 작업이다. Song 코드·프로세스·배포에는 접근하거나 변경하지 않았다.

## 구현

- [도구·실행·제약](../ops/public-host/EXPORT.md): 닫힌 SQLite 스냅샷 → 기존 summarizeTelemetry SQL → 비공개 집계 포장 JSON.
- 읽기 전용 연결·하나의 읽기 트랜잭션·전후 SHA/파일 상태 대조, sidecar/WAL/뷰/잘못된 스키마/값/덮어쓰기 거부.
- 원본 ID·원본 경로 미출력, UTC 날짜/현재 시각 만료 기준, coverage=unverified.
- 실제 로컬 D1과 같은 합성 자료를 넣어 집계 일치를 확인했다. 원본 파일·폴더 불변도 확인했다.
- 추가 검토에서 Mac의 대소문자 구분 없는 경로, 복합 PK·NULL ID로 세션이 부풀려질 수 있는 경우를 보강했다.
- 기존 retention 테스트는 고정 10/12 합성 시계와 실제 HTTP 시계가 섞여 10/15부터 1행이 남았다.
  삭제 검사 시각을 두 시계 모두의 만료 이후로 정해 날짜 경과에 의한 실패를 수정했다. 서비스 수집/삭제 코드는 변경하지 않았다.

## 보고서 연결 — 사용자 승인 후 구현

앞선 자동 승인 검토 거절 후 사용자가 “우리 보고서 파일 수정·검증 승인”을 명시했다(2026-10-15).
승인 범위의 우리 report.mjs와 관련 검사·문서를 수정했다. 전체 스냅샷 포장 파일을 보고서 입력에 유지하며,
빈/만료 자료는 no_data와 null, 남은 관련 행은 partial_data, OFF 채널은 null로 표시한다.
보고 기간과 겹치는 UTC 날짜 전체 합계임을 명시하고 정확한 시각 구간 수치와 수집·보존 누락은 미측정으로 남긴다.
기존 요약 입력은 호환된다. 생성 시각/원본 SHA/요약 날짜는 운영자 JSON에만 보존한다.
집계 검증을 공유 함수로 분리하여 내보내기 도구의 가상 보고서 입력을 제거했다.

합성 SQLite → 내보내기 JSON → 실제 Markdown/JSON 보고서 파일을 연결했고 기존·신규 포함 Node209검사를 통과했다.
최종 고정 커밋의 다른 모델 검토를 진행 중이다. 기존 내보내기 코드 검토 결과로 연결 코드까지 통과했다고 간주하지 않는다.

## 검사와 검토

내보내기 11검사, 전체 운영 Node 197검사, 체크리스트 8검사를 통과했다. Python 하위 프로세스 한글 디코딩 경고는 PYTHONUTF8=1 재검사에서 없어졌고 8검사를 통과했다. 최종 소스·SHA·명령은 [영수증](results/ops/ws_report2_snapshot_20261015.json)에 기록했다.
증거는 합성 자료와 로컬 D1이며 실제 Cloudflare 취득·실경기 이용량·큰 DB 성능은 미측정이다.

## 다른 모델 1차 검토와 수정

`gpt-5.6-sol`이 `687256c09b66ee9cc1a5445220aad50718373005`를 검토해 2건을 재현했다.
1. 90일 초과/정수 일이 아닌 보존 기간도 받아 잘못된 행이 오래 집계될 수 있었다. 수집기가 쓰는 1~90 정수 일 TTL을 양 테이블에서 검증한다.
2. `table_info`가 generated 열을 숨겨 추가 열을 놓쳤다. `table_xinfo`로 바꾸고 hidden/generated 열을 거부한다.

두 건을 수정했고 관련 12검사를 통과했다. 검토자 환경의 Miniflare 2검사는 loopback 권한 거부로 실행되지 않았으며,
부모 환경의 실제 로컬 D1 2검사는 통과했다. 이를 검토자 독립 실행 통과로 바꿔 기록하지 않는다.
최종 코드 `d60d45b67088fee7aec206244559343c8c9233e1`의 같은 검토자 재검토는 **PASS**다.
독립 합성4검사 통과, 원래 두 반례는 각각 `snapshot_invalid_row`/`snapshot_schema_mismatch`로 거부됐다.
부모 환경에서는 최종 전체 Node197검사(실제 로컬 Miniflare 포함)를 통과했다. 체크리스트8·문서 상대 링크59개도 통과했다.
작성자는 GPT-6 계열이며 정확한 제품 모델 ID는 확인하지 못했다. 검토 모델은 명시적으로 선택된 `gpt-5.6-sol`이다.
이 결과를 과거 Codex 전체 작성 묶음의 작성 모델 식별이나 전체 출시 승인으로 소급하지 않는다.
