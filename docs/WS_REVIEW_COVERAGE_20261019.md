명시적 파일 영수증, 문서에 명시한 변경분, 과거 glob 범위를 구분한다.
같은 커밋에 들어 있었다는 이유만으로 검토했다고 기록하지 않았다.

## 재현

저장소에서 `git --no-replace-objects show COMMIT:path`로 각 바이트를 읽고
SHA-256을 계산한다. Git blob OID도 함께 비교한다. 일괄 확인은
`git --no-replace-objects cat-file --batch`에 같은 `COMMIT:path` 목록을 넣으면 된다.
해시 기준은 Git 원문 바이트이며 Windows 작업트리의 CRLF 변환본과 구분한다.
구체 비교 대상과 전체 해시는 연결한 JSON에 있다. 조회는 로컬 Git·문서 읽기뿐이다.

소스가 바뀌면 해당 파일의 연결은 다시 확인해야 한다. 새 커밋·원문 해시·검토 범위를 갱신하고,
같은 커밋에 들어 있었다는 이유만으로 검토 완료를 승계하지 않는다.
