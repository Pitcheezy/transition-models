기본 시연은 저장 파일을 사용하며 모델·로그인·인터넷이 필요하지 않습니다.
Python·Node 없이 파일을 열 수 있지만 브라우저 정책에 따라 로컬 HTTP가 필요할 수 있습니다.
파일 기능이 제한되면 보안 설정을 바꾸지 말고 Python 설치 환경에서
압축 푼 폴더를 터미널로 연 다음 아래 명령을 실행하세요.
  python -m http.server 8786 --bind 127.0.0.1
Mac에서 python이 없고 python3가 있으면 python3를 사용하세요.
http://127.0.0.1:8786/START_HERE.html 로 접속합니다. 종료는 Ctrl+C입니다.
첫 타석 화면과 파일 선택·SHA256 검사 모두 이 방법으로 열 수 있습니다.
발표 중 새 응답 수신이나 서버·팀원 서비스 호출은 필요 없습니다.

링크는 새 탭으로 열리므로 시작 안내 탭을 남겨 두세요.

실제 Mac/iPhone 열람·본인 낭독·Song 화면 리허설은 별도 확인해야 합니다.

중요한 범위
- 첫 타석은 실제로 전달받은 과거 모델 응답과 공식 영상 3개를 투구 키로 연결한 데모입니다.
- 영상 종료는 저장된 사후 결과를 보여 주는 계기이며 영상에서 결과를 자동 판정하지 않습니다.
- 개별 클립이며 연속 중계 자동 동기화나 실시간 모델 추론을 검증하지 않았습니다.
- 구종 선택 비중은 스트라이크·볼·파울·안타의 사건확률이 아닙니다.
- 추천 위치는 과거 실제 도달 분포의 근사이며 포수 요구나 검증된 목표 정책이 아닙니다.
- 3구 미트 표시는 기존 condensed 영상 3084번 정지 프레임의 미검토 AI 추정입니다.
  새 공식 영상의 시간축·좌표로 옮기지 않았고 높이·투수 의도·제구 오차를 검증하지 않았습니다.
- 1구 시작에는 메인 점수판이 없어 상황은 공식 기록에 근거합니다. 시작 화면 OCR 결과가 아닙니다.
- 홈·서비스 콘셉트 예시와 합성 수신 테스트는 첫 타석의 실제 저장 응답과 구별합니다.
- M3의 기존 평가와 이번 데모 연결은 별개이며 새로운 독립 정확도 검증으로 세지 않습니다.
- 결과 숨김은 화면 표시 기능이며 저장 파일의 사후 정보를 보호하는 보안 경계가 아닙니다.

비공개 현장·지정 팀원 파일 전달용
