01 · 실제 저장 응답과 공식 세 구

02 · 3구의 별도 정지 장면

3구에서만 별도로 판독한 정지 장면을 열 수 있습니다. 초록 점은 이 장면에 저장된 미검토 AI 미트 중심입니다. 영상 전체를 추적한 결과나 포수의 실제 요구 위치는 아닙니다.

CV 평가는 별도 두 경기에서 했습니다. 전체 86장 중 AI 출력은 58장, 기권은 28장입니다. 대표 그림은 크리스 세일 대 브라이슨 스톳 사례이며, 초록 원은 AI, 빨간 십자는 사람 표시입니다.

현재 확인한 것은 저장 응답·투구 영상의 대응과 미트 판독의 사람 표시 대비 차이입니다. 실시간 추론이나 자동 중계 동기화, 제구 실책 판정은 아닙니다. 다음은 미트 주석의 독립 검토와 새 영상 검증, 실제 연속 입력의 처리 시간·공개 시점 확인입니다.
