# 팀원 파일과 우리 전달팩의 차이 — 2026-10-11

현재 Windows 노트북에서 팀원에게 받은 데이터를 검토할 수 있다. Mac 전송은 Mac 실기기 검사를 할 때만 필요하며 노트북 개발의 선행 조건이 아니다. 이 설명은 실제 ZIP 목록·CRC와 기존 전달 영수증을 대조했다. 파일이나 메시지를 팀원에게 전송한 기록은 아니다.

## 세 ZIP은 용도가 다르다

v5에는 이후 개발한 CV-30 관측 재생 화면이 들어 있지 않다. 소스팩과 영상팩을 서로 대체하지 않는다. 원문·영상팩은 Git 제외이며 공개 업로드 대상이 아니다.

자료는 경기 후 생성한 아카이브 재생 응답이다. 데이터 무결성·화면 연결과 별개로, 실제 서버의 로딩 커밋·가중치·라이브 사전 가용성은 확인되지 않았다.

## 다음에 모델을 직접 실행하려면

기존 결과 JSON을 다시 요청할 필요는 없다. 독립 실행에는 합의된 모델/API 소스 버전, 시작 명령과 의존성 lock, 가중치·프로필·보정 자료 및 SHA/크기 manifest, 입력/출력 예제, 지원 범위와 as-of/cutoff 의미가 필요하다. 전달받은 번들은 우리 환경의 별도 경로에서 실행하고 팀원 저장소는 수정하지 않는다. 이 설명은 새 번들의 수신·실행 완료를 뜻하지 않는다.

## 팀원에게 복사할 메시지

형, 지난번 주신 `pitcheezy-service-game-v2.zip`은849843 경기 전체262구·71타석의 상황, 추천 후보, 실제 결과, 미트 상태와 계약·해시 정보가 든 결과 스냅샷으로 확인했습니다. 모델 코드나 가중치·영상은 포함되지 않아 현재는 저장 응답을 우리 화면에 연결했습니다.

우리 쪽은 이식용 `service_review_source_20261010_v5.zip`과 비공개 화면 확인용 `service_review_video_20261010_v5.zip`을 구분해 준비했습니다. 소스팩에는 검증·정규화·화면·서버·테스트가, 영상팩에는 전체 경기 결과와 첫 타석3개 영상·실행기가 들어 있습니다. 추천 → 실제 결과 공개 → 제공된 미트 가로 위치 표시를 볼 수 있습니다. CV-30은 별도 개발 화면이고 이 v5팩에는 없습니다.

구종 비중을 사건확률로 바꾸거나 미트 높이·제구 책임을 새로 계산하지 않았습니다. Windows 실행 확인과 Mac 실기기 검사는 구분하며, Mac 화면 검사는 아직 대기입니다. 형 저장소는 변경하지 않았습니다.

이후 모델을 우리 환경에서 직접 실행하려면 별도의 실행 번들·가중치/프로필/보정 자료·의존성/시작 명령·버전/입출력 예제가 필요합니다. 화면 이식과 모델 실행을 나눠 진행하면 됩니다.
