2026-10-21. 아래 구분선 뒤가 보낼 문안이다. 이 초안은 게시·일정 확정·배포 승인이 아니다.

---
형, final2 실행본과 v4.4 전달팩 받았고 우리 노트북에서 확인했어.

**파일 확인**
- final2: 47,695 bytes / SHA-256 `f8f1c48a9925913857827144e8fb997016417d4f6cac7b71d333d25a33646796`
- v4.4: 188,620 bytes / SHA-256 `c431b3f737c4d7eaa1e8d8e1e119b2c25dfb32f65588f7c8dcda7c23c1bab18e`
- 전달 메시지의 앞뒤 SHA와 일치해. 우리 조회에서 #38 최신 최종 회신은 아직 확인되지 않아서 위 전체값도 형 보관값과 대조 부탁해.
- manifest22파일·실행본 해시목록6파일·source/build8개와 등록서가 일치하고, 우리 runtime5파일도 기대값과 같아. 실제 서버 배포 여부와는 구분했어.
- REVIEW-007에서 작성 `claude-opus-5-5` / 검토 `claude-fable-5-1` 및 최종 파일 SHA를 확인했어. N23 사전 거부 코드는 확인했지만 형의21/14/26개 검사를 우리가 재실행한 것은 아니야. 이전 REVIEW-005/006 원문·테스트는 이번 팩에 없으므로 전체 검토를 독립 재현했다고 기록하지 않을게.

**우리 쪽 준비**
- 새 화면을 우리 Worker/R2 로컬 환경에 붙여 추천·결과·미지원 참고통계·health 갱신·304·철회/복구·안내 전환을 점검했어. 새 비공개 배포 후보도 만들고 파일/설정 검사를 했어.
- Windows에서는 제공 발행기가 fcntl을 요구해서 원본 offline 명령은 실행되지 않아. 발행기는 형 Mac, 호스팅은 우리 노트북이 담당하는 구조로 준비했어. 서로의 레포/장비를 수정하지 않았어.
- 실제 공동 접속·배포·권한 발급은 아직 하지 않았어. 수집/피드백은 OFF 유지야.

**비상 안내 스위치 답변**
- 구현됐고10/16 본인 전용 실제 합성 시험에서 ON503/OFF200을 확인했어. 현재 서버 version·설정·운영자 자격은 시험 전에 다시 확인해야 해.
- 발행키와 분리된 안내 전용 토큰을 써. 자동 만료는 없고 담당자가 digest 제거/교체로 회수해. 양쪽 운영자가 각각 쓸 권한은 아직 전달하지 않았어.
- 현재 상태/ETag 조회 → 조건부 ON → 상태·감사·화면 확인, 복구 결정 후 새ETag로 OFF 순서야. 비밀값·실제 주소는 이슈에 적지 않고 별도로 맞추자.
- 이번 노트북 loopback에서 ON 요청18.81ms, 성공 뒤 첫 안내15.18ms / OFF 요청19.02ms, 성공 뒤 첫 정상22.17ms였어. 한 환경의 측정이며 실제 CDN 전환시간은 미측정이야. 이미 열린 화면은 폴링 주기에 따라 달라져.
- **확인 요청:** `maintenance`와 `data_hold`를 켜면 새로고침한 화면은503 안내만 나오지만, 이미 열린 화면에는 안내와 ‘마지막으로 받은 추천’ 카드·존이 함께 남아. 비상 내림을 완전한 화면 철회로 볼 경우 이 부분을 숨기는 수정이 필요해 보여. 우리 쪽에서는 화면 소스를 고치지 않았고 합성 캡처를 반환팩에 넣었어.

**GATE-06 합의 제안**
- 정상 종료만 ‘정확한 키/만료 제한 유지 → 발행digest 교체 → 옛키401 확인 → 업로드OFF’로 맞추는 안을 제안해. 긴급은 무조건OFF부터,401을 얻기 위해 다시 켜지 않는 규칙 유지야. 아직 합의된 순서로 실행하지 않았어.
- 서비스 정상경로 최대32회안: 본시험18 + 후속3 + 관람로그인/회수확인2 + 안내점검9. Cloudflare 관리·추가 사전점검·실패정리와 이미 열린 화면 폴링검사는 별도 원장으로 세자.32회를 전체 시험 총량으로 확정하자는 뜻은 아니야.
- 10/22(목) 오전~14:00 설정 →18:00~19:30 시험 →21:00 판단은 제안 일정으로 접수했어. 우리 담당 가능 여부·접속/배포 범위와 창별GO를 확인한 후 확정 회신할게.

결과 인수 시에는 공개요약만 보지 않고 종료코드와 wrapper-log를 함께 볼게. 비밀검사 실패 시 요약의 PASS가 남을 수 있는 조건부 정적 경로가 있어서, 실패 로그/비0종료면 공유를 막는 조건으로 정리했어(실행 재현은 하지 않음).

관련 요청은 #38, 우리 수신 기록은 #18/#3에서 이어가자. 비공개 소스·원본 ZIP은 공개하지 않을게. 반환팩에는 우리 검증 요약·원장 협의안·합성 화면 증거만 넣었어.
