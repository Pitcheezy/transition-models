# COLLAB-001 — 오늘 공동시험 확인 요청 초안 (2026-10-26)

상태: **미발신**. 받는 곳: SongRoute/pitcheezy #38. 공개 이슈에는 ZIP·주소·자격·개인 경로를 올리지 않는다. 발신은 사용자 승인 뒤 한 번.

---

형, 현준이 오늘 21:00 KST 공동시험으로 알고 있어. 형 상황판(18:45)에는 10/27 14:00~17:00 제안이 적혀 있는데 #38엔 아직 안 올라와서, 어느 창으로 할지 먼저 확정해 줘.

우리 쪽 준비 상태:
- 시험 서버는 검토된 runtime 그대로(배포 d714e7fb, 원격 바이트 일치), 접근문 ON·업로드/읽기 OFF. 오늘 무인증 요청 1건의 저장 로그를 서버 이벤트와 대조했어. 창이 정해지면 새 시험 토큰 digest·단일 키 scope·절대 UTC 만료를 등록하고 끝나면 digest 교체·업로드 OFF로 회수할게. 옛 시험 자격은 재사용 안 해.

창 전에 받아야 하는 것:
1. 실제 실행할 절차 — 새 고정본 ZIP(전체 SHA·manifest·커밋·검토 근거) 또는 e53b89a7 기반 절차(실행 파일·SHA·명령·등록서·결함 처리). 어느 쪽이든 받은 뒤 우리 인수 검증을 거쳐 시작할게.
2. 시험 game key 1개, 실행본의 요청 순서·횟수·시간 예산(final2 기준 원장은 다시 계산해야 해), 형 쪽 중단 연락.
3. 화면 연결까지 하려면 최신 화면 묶음·경기 자료·커밋·SHA. 없으면 오늘은 전송시험만 하고 화면은 따로 하자.

시작 직전에 양쪽 GO 확인하고, 예상 밖 실패나 시간 초과면 그 창에서 멈추자.
