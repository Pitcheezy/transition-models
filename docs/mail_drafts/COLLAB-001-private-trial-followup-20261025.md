# COLLAB-001 — 호스트 점검 결과·다음 공동시험 조건 (미발신 초안)

발신 승인 전. 수신 대상은 기존 Song mail #38이다. 비공개 ZIP·접속 주소·자격·원시 로그는 공개 이슈에 붙이지 않는다.

형, 노트북에서 요청한 Cloudflare 점검을 진행했어.

- 현재 배포 버전 `8e4f50e9-9bf4-4564-977f-86af1b576220`, 트래픽100%를 확인했어. 최종 Git/runtime와의 원본 대응은 아직 미확인이야.
- 요청 로그100%·호출 기록·대시보드 저장을 켰어. 두 번의 홈 조회와 자동 아이콘 요청으로 저장4이벤트를 확인했고, 이후 JSON 원본을 내려받아4건 모두HTTP401과실행버전을 대조했어. 무인증 접속 제한 확인이며 회수 후 옛 자격 거부 시험은 아니야.
- 10/25 01:05:08 KST 설정 변경 감사 기록도 확인했어. 활성 코드 버전은 그대로고, 접근문ON·업로드/자료읽기/수집/피드백OFF를 유지했어. 발행 제한binding은60회/60초로 조회됐어. 전세계 합산 요청 한도라는 뜻은 아니야.
- 실제 `PUBLISH_KEY_SCOPE`와 `PUBLISH_EXPIRES_AT`는 아직 설정돼 있지 않아. 기존 자격의 보관 위치도 확인하지 못해 실제 회수는 미실행이야. 유효한 자격으로 성공 확인 → 회수 → 옛 자격 거부를 대조해야 하고, 업로드OFF의503으로 대신하지 않을게.
- 원시 로그에는 클라이언트 메타데이터가 포함돼 있어 공개하지 않고 시각·method·경로·상태·버전만 추린 영수증을 준비했어. 원본20,587bytes의SHA-256은 `6753e5bae2938e256e3067afad60b0cd2967958c9b9f9a86695f316bf99777b5`이고, 공유 영수증은 `docs/results/ops/ws_host_log_export_20261025.json`이야. 로그가 생겼다고GATE-06 전체를 합격 처리하지 않을게.

10/25 D181은 공개 배포 없이 비공개 로컬 운영·RS 그림자, 3차전 전 공동시험1회로 이해했어. 이전에 말한 ‘27일 서비스’도 이 범위인지 맞추고 새 시험 시간과 양측GO를 정하자.

다음 비공개 전달 때 아래를 함께 부탁할게.

1. 실제 공동시험에 쓸 실행본·화면 빌드·등록서의 고정 커밋, 전체SHA-256·크기·재현 명령.
2. 기존3건(ONEKEY-PROBE-01·OPS-ALERT-JSON01·OPS-CRED-01)과 새2건(안내 뒤 일반 실패에서 추천 재노출·디스크 기록 실패 때 감독/감시 종료 승격 누락)의 수정/잔존 상태와 시험 영향.
3. 최종 파일을 대상으로 한 작성/검토 모델·검토 커밋·회귀 결과. 과거 검토를 새 파일에 그대로 적용하지 않을게.

수신 기준은 파일/등록/검토 대상 일치, 그리고 안내 후 일반 실패에도 이미 숨긴 카드·존이 다시 나오지 않으며 유효한 정상 응답 이후에만 복원되는 것이야. 디스크 기록 실패는 감독/감시 결과까지 남긴 재현 증거를 대조할게. 형 코드·Mac을 직접 조작하지 않을게.

현재 근거는 `docs/WS_HOST_PREFLIGHT_20261025.md`와 `docs/results/ops/ws_host_preflight_20261025.json`이야. 이 회신은 타인 접속 허용·새 시험GO·실경기·공개 전환 승인이 아니야. 다음에는 고정 후보·단일키/UTC만료·시험 창·요청 원장과 회수 담당을 맞추자.
