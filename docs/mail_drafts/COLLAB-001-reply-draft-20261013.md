**업로드 API 모양 (우리 제안, 문서 그대로)**
- `PUT /_publish/v1/<경로>`: `Authorization: Bearer <토큰>`, `Content-Type: application/json`, `X-Content-SHA256: <원본 바이트 sha256>`, 첫 저장 `If-None-Match: *`, 갱신 `If-Match: "<직전 ETag>"`.
- `DELETE /_publish/v1/<경로>`: `If-Match: "<현재 ETag>"` 필수. 공개 GET/HEAD는 즉시 404.
- `HEAD /_publish/v1/<경로>`: 현재 ETag·원본 SHA·삭제 표식. 412는 충돌(자동 재전송 없음). 토큰은 사람끼리 비공개 전달.
