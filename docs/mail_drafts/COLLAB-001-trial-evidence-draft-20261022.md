# COLLAB-001 — 시험 증거 조건 후속 초안 (미발신)

이 초안은 미발신 이력으로 보존한다. #38 새 회신 이후의 현재 문안은 [10/23 네 질문 회신](COLLAB-001-host-answers-draft-20261023.md)을 사용한다.

형, 반환팩 v2 수신·해시/무결성 검사 보고를 확인했어. 기존34기능 재실행과 구분한 점도 반영했어.

TRIAGE에 세 결함이 아직 미수정이고 절차로 대응한다는 내용을 확인했어. 우리 GATE-06에는 game_key/scope/expiry 고정과 변경 시 회차 무효를 합의 전 보완안으로 정리했어.

서버 증거 쪽에서 먼저 확인할 점이 있어. 현재 우리 코드에는 발행 요청별 자체 로그가 없고, scope/expiry는 서버 설정이야. 다른 키와 만료가 모두 HEAD403이라 상태코드만으로 구분할 수도 없어. 실제 Cloudflare에 기존 요청 로그와 관리 변경 이력이 있는지 조회 중이며, 확보 전에는 이 합격 조건을 충족한다고 약속할 수 없어.

배포 version·고정 설정/관리 변경 이력·요청 시각/메서드/경로/상태를 함께 대조하는 방식으로 확인하려고 해. 필요한 기록이 없으면 조건은 미충족으로 두고 수정 실행본이나 다른 근거를 따로 합의하자. 비밀값이나 Authorization/Cookie는 기록·공개하지 않을게.

미수정 실행본의 절차 대응, 외부 새로고침 공지·수동 감시는 아직 우리 쪽 수용/GO로 처리하지 않았어. 기존 참석 가능 창 이후 실행이라면 새 시각과 전체 조건을 다시 맞추자. 세 건의 상태/영향과 근거는 요청한 대로 #38에 이어 남겨줘.

이 문안은 추가 발신 승인 전 초안이며, 이번 문서 작업에서 게시하지 않았다.
