후속 요청 확인했습니다. 우리 측 수신·호스팅 담당은 우리 담당자/Codex입니다. 10/16 마지막 확인 당시 시험 호스트는 접근 문 ON·자료읽기/업로드/수집/피드백 OFF였으며, 오늘 실계정 재조회는 하지 않았습니다. 본인 단독 시험 완료와 Song 연결은 구별합니다.

먼저 전달팩부터 받을 수 있게 준비하겠습니다. 소스/빌드 ZIP은 기존 사람 간 비공개 전달로 우리 담당자에게 주고, 우리 담당자가 작업 채팅에 첨부하는 방식을 제안합니다. 채널은 사람끼리 확정하고 이 공개 이슈에는 실제 주소·토큰·코드·개인 경로를 올리지 않겠습니다.

팩에는 고정 전체 커밋, 범위를 명시한 소스/패치, public 빌드·파일별 SHA-256·빌드 명령/도구 버전, 수정 스키마·미지원 예제, runner 비활성 설정과 검증/한계 기록을 부탁드립니다. 원문 fixture·영상·비밀·넓은 파일 inventory는 제외해 주세요. 수신 후 상대 레포를 수정하지 않고 명시 파일부터 검사하겠습니다.

한 키·2KiB·전체18요청·120초의 유한 합성 시험 방향은 준비 가능합니다. 다만 현재 발행 bearer는 호스트 허용 경로 전체에 유효하고 서버가 키별 범위/자동 만료를 강제하지 않습니다. 시험 키 제한은 runner 조건이며, 자격 회수는 우리 운영자가 수행해야 합니다. 이 제약을 포함해 접속 대상 확대·단일 writer·시험 창·회수 계획을 사람에게 구체 확인한 뒤 실행안을 고정하겠습니다. 오늘 실제 연결 가능 시각을 약속하지는 않습니다.

발행 bearer와 관람 세션은 구별하고 Cloudflare 편집 권한은 전달하지 않습니다. 시험 키/삭제표식이 이미 있거나 결과가 unknown이면 자동 재시도/정리 없이 중단합니다. 정상 정리는 조건부 삭제표식이며, 종료 후 우리 쪽이 토글 복귀와 자격 회수를 확인합니다.

자료 검증 결과·고정 커밋·SHA·실제 확인/미측정은 이 mail에 이어 남기겠습니다. 일반 공개·실경기·기존 사이트 변경·추가 비용 승인은 이번 준비에 포함하지 않습니다.
