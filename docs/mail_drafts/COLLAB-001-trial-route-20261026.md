# COLLAB-001 — 시험 경로·다음 창 확인 요청 초안

상태: 미발신. 받는 곳: SongRoute/pitcheezy #38. 공개 이슈에는 ZIP·주소·자격·개인 경로를 올리지 않는다.

형, 우리 쪽에서 바로 할 수 있는 서버 확인을 마쳤어.

- 10/25 본인 시험에서 관람200→회수401, 발행HEAD404→회수401→업로드OFF503과 관련 저장 로그를 확인했어. 오늘 관리 API 조회에서도 배포 버전은 같고 접근문ON·업로드/자료읽기/이용기록/피드백OFF야.
- 안내 기능13건은 통과했지만 저장 로그는12/13이라 전체 증거는 HOLD야. 오늘 설정에서는 Logs 하위 ON/저장100%와 상위 observability=false가 함께 나와, 다음 시험의 새 요청을 실제 저장 이벤트와 대조해야 해. 오늘 새 서비스 요청은 보내지 않았어.
- 보낸 21,561bytes 호스트 증거팩의 수신 여부도 확인 부탁해. 새로 포장해 보내지는 않을게.

이번 시험을 어느 경로로 할지만 #38에 확정해 줘.
1. 앞서 예고한 새 v7/v4.5 인수 후 시험
2. #37에 적힌 기존 000e4ba0·v7 wrapper 미사용의 제한 시험

2번이라면 정확히 실행할 파일·명령·등록/전체SHA·검토 근거, 미수정 결함을 어떻게 제한할지 비공개 전달 부탁해. 둘 중 어느 쪽이든 우리 인수 검증과 양쪽 수용 후 실행할게. 전송만 확인하는 시험이라면 최신 화면·서비스 합격과 구분하자.

경로가 정해지면 새 시험 시간과 중단 연락/담당을 맞추자. Song은 단일 writer, 우리는 호스트 설정·요청/로그 대조·회수 담당으로 준비할게. 새 자격·키·scope·expiry·요청 원장·양측 GO를 고정하고 시작하자. 예전 시험 자격은 재사용하지 않을게.
