## 회신 — 고정 빌드 fba6b2ff 인수 결과와 전시 호스트 구성

형, 회신 3·4 받았고 그 구성대로 갈게. 5항목 전부 진행 중이고, 아래는 지금까지 확인한 것과 물어볼 것.

### 1. 받은 묶음 (인수 완료)
- ZIP 867,682 bytes, SHA-256 `af10293d…77a4bc` 일치. manifest 28파일 원본·LF 정규화 해시 모두 일치, 압축 오류 없음. 원본은 수정하지 않았어.
- 849843: 262구·71타석, 추천 246·미지원 16 확인.
- 로컬 Chrome(1440/390/320폭): 첫 투구·타석 선택, 안내 ON 때 추천·존·목록 숨김, 안내 뒤 일반 오류에도 숨김 유지, 정상 응답 뒤 새로고침 없이 복원. 네 notice-hide-smoke 결과와 같았어.
- 우리 호스트 코드(gateway·안내·접근 코드)를 로컬에서 띄워 같은 빌드를 올려 봤어: 자료 24개 업로드 뒤 공개 `/v1`에서 24개 모두 바이트 일치, 안내 ON→OFF 때 앱이 약 9~10초 뒤 숨기고 약 3~4초 뒤 복원(로컬 Chrome). 실제 Cloudflare는 아직 아니야.

### 2. 호스트 구성 (제안, 이번 주 실행)
- `pitcheezy.com`은 홈 한 페이지(영상·소개·"서비스 열기")만 남기고 Cloudflare 정적 호스트로 옮겨. Sites는 내릴게.
- 네 앱은 `pitcheezy.com` 하위 도메인(이름은 시험 뒤 확정)에 우리 Worker로. 화면 4개는 정적 파일, `v1/*.json` 24개는 업로드 API로 올려서 발행 기록 형식으로 저장돼. 파일 바이트는 그대로고, 응답은 `no-store`·ETag야(우리 응답은 no-store라 지시어는 다르지만 로컬에서 앱 동작 차이는 없었어).
- 포스터 QR은 지금처럼 `pitcheezy.com` 홈으로 두고, 홈의 "서비스 열기" 한 번으로 네 앱(`?game=849843`)이 열려. 앱으로 바로 가는 QR을 최종 포스터에 넣고 싶으면 말해 줘. 11/11 공동시험까지는 접근 코드 켜 두고, 11/21 리허설부터 끌 생각이야. 시험 전에 비공개로 주소·코드 줄게.
- 연결 검사 결과는 여기 #38에 SHA·요약만 남길게.

### 3. 확인해 줄 것
- `v1/dates.json`엔 23일이 있는데 `v1/games/` 파일은 5일(09-30, 10-01, 10-02, 10-04, 10-05)뿐이야. 나머지 18일을 누르면 앱이 "이 날짜에는 경기가 없어요"를 보여 줘. 전시 진입은 `?game=849843`로 고정할 건데, 18일은 그대로 둬도 되는지 아니면 목록을 맞춘 빌드를 줄지 알려줘.
- 24개 자료엔 849843 외 14경기(849844 포함)도 들어 있어. 받은 그대로 24개를 다 올리는 걸로 할게. 빼고 싶은 경기 있으면 말해 줘.

### 4. 영상 (전달 준비 완료)
- 849843 공식 클립 261개 + 등록부(투구 ID → 파일·SHA·길이) + 영상 전용 플레이어 팩 v4. 약 1.31GB, SHA-256 `32f4377e…`. 비공개 경로로 줄게.
- 69타석 2구는 네 자료(FC)와 MLB 기록(SL)의 구종이 달라서 영상에서 뺐어. 플레이어는 그 공에서 멈추고 수동으로 다음 공을 고르게 돼 있어.
- 모니터 2 표시는 네 앱 기준(이닝 초/말·타자·N구)으로 맞췄어. 풀 중계는 구하지 못해서 클립 체인으로 확정하려고 해.
