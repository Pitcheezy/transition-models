# Song #38 회신 초안 — 고정 빌드 인수 결과·호스트 구성 (미발신)

상태: **초안, 미발신.** 발신 여부·시점은 사용자가 정한다. 공개 이슈이므로 비공개 주소·자격·로컬 경로는 넣지 않는다.

---

## 회신 — 고정 빌드 fba6b2ff 로컬 인수 결과

형, 회신3·4 받았고 그 구성대로 갈게. 모니터 1은 형 서비스, 모니터 2는 우리 클립 체인 플레이어, 같은 투구 ID로 수동으로 맞춰.

### 1. 받은 묶음
- ZIP 867,682 bytes, SHA-256 `af10293d…77a4bc` 일치. manifest 28파일의 원본·줄바꿈 정규화 해시 모두 일치, 압축 오류 없음.
- 849843: 262구·71타석, 추천 246·미지원 16 확인. 원본 파일은 수정하지 않았어.
- 로컬 브라우저(1440/390/320폭)에서 첫 투구·타석 선택, 안내 ON 때 추천·존·목록 숨김, 안내 뒤 일반 오류에도 숨김 유지, 정상 응답 뒤 새로고침 없이 복원 확인.

### 2. 확인해 줄 것 — 날짜 목록
- `v1/dates.json`에 23일이 있는데 `v1/games/` 파일은 5일(09-30, 10-01, 10-02, 10-04, 10-05)뿐이야. 나머지 18일을 누르면 자료가 없어.
- 전시 진입은 `./?game=849843`로 고정할 생각이야. 18일은 그대로 둬도 되는지, 아니면 목록을 맞춘 빌드를 줄지 알려줘.
- 24개 자료에는 849843 외 13경기도 들어 있어. 호스트에는 받은 24개를 그대로 올리는 걸로 할까?

### 3. 호스트에 올리는 방식
- 우리 Worker는 `/v1/*`를 업로드 API로 받은 기록에서만 읽어. 그래서 화면 4개는 정적 파일로, v1 24개는 업로드 API로 한 파일씩 올릴게. 파일 바이트는 그대로야.
- 같은 구성을 우리 컴퓨터에서 우리 gateway로 먼저 돌려 봤어(리허설 결과 요약을 여기에).
- 실제 시험 호스트 반영·도메인 연결은 우리 쪽 결정 후 진행하고, 11/11 공동시험 전에 주소를 비공개로 줄게.

### 4. 영상
- 849843 공식 클립 261개 등록부(투구 ID → 파일·SHA)와 영상 전용 플레이어 팩을 만들었어. 69타석 2구는 구종 불일치(형 자료 FC, MLB 기록 SL)라 영상에서 뺐어.
- 전달팩은 약 1.31GB라 비공개 경로로 줄게.

### 5. 교차 검토
