## 앱 브라우저에서 실제로 본 것

사이트 폴더만 제공하는 임시 로컬 서버와 Codex 앱 브라우저를 사용했다. 서버는 loopback 주소에만 연결했다. 기존 서버와 기존 탭, 실제 호스트 설정은 그대로 두었다. 이번 확인을 새 Mac·Safari·아이폰 검사나 사용자 직접 리허설로 세지 않는다.

1. 첫 화면에서 투구 키 `849843:1:1`, Michael King 대 Pete Crow-Armstrong, 결과 숨김 상태를 확인했다.
2. 1구의 실제 재생이 끝난 뒤 루킹 스트라이크·싱커·96.3mph가 표시됐다.
3. 2구로 전환했을 때 결과 숨김과 0볼 1스트라이크를 확인했다. 실제 재생이 끝난 뒤 헛스윙·스위퍼·86.4mph가 표시됐다.
4. 3구로 전환했을 때 결과 숨김, 0볼 2스트라이크, 미트 버튼 비활성을 확인했다. 실제 재생이 끝난 뒤 삼진·포심·97.6mph와 미트 가로 위치 −0.0517ft가 표시됐다.
5. **미트 판독 장면**을 눌러 별도의 정지 이미지, AI 미트 점, 미검토 추정이라는 범례를 시각적으로 확인했다. 이를 공식 영상의 추적 결과로 해석하지 않는다.
6. 결과를 다시 숨기면 정지 이미지와 미트 값이 제거되고 미트 버튼이 비활성화됐다.
7. 영상을 재생하지 않고 **현재 투구 결과 공개**를 눌러 수동 대체 동선도 확인했다. 실제 네트워크 장애를 주입한 검사는 아니다.

이번에 하지 않은 것은 다음과 같다. 네이티브 영상 되감기의 경계 동작, 일시정지·재개 반복, 좁은 화면의 신규 검사, 오디오 품질, 외부 기기, 사용자 낭독 시간, 새 Song UI, 합성 발행기 공동시험, 부하·요금제 시험. 위 7개 관찰을 해당 기능 전체의 새로운 회귀 평가로 확대하지 않는다.

## 자료와 검토

현재 패키지 생성 도구가 사용하는 사이트 파일 31개와 기존 CV 요약 PNG·PPTX는 존재한다. 예전 v4 ZIP·압축 해제 폴더와 비공개 비교 갤러리는 현재 작업트리의 명시된 경로에서 찾지 못했다. 전체 디스크에 없다고 단정하지 않는다.

두 보조 에이전트가 기여 근거와 실행 절차를 따로 읽고, 수치의 의미, 실제 버튼명, 되감기와 결과 숨김의 차이, 기존 Windows 확인 범위를 교정했다. 같은 계열의 별도 문서 검토이며, 운영 코드에 필요한 다른 모델의 검토를 새로 충족했다는 주장이 아니다.

문서 SHA와 고정 원자료 파일 확인 결과는 본 작업의 PR 종료 기록에 남긴다. 실제 운영의 남은 일은 [현재 인계](../WS_OPERATIONS_HANDOFF.md), 필요한 다음 입력은 [준비 목록](README.md)을 따른다. 안내 로그는 12/13건으로 전체 합격 보류이며, 새 최종본·공동시험·공개 GO 대기를 유지한다.

## 준비표와 최종 문서 검사

준비표 `index.html`을 앱 브라우저에서 열어 제목·8개 기여·지표·한계와 원고 연결을 시각 확인했다. 신규 문서는 상대 링크·제어문자·공개 정보 범위와 고정 자료 바이트를 검사한다. `preparation_manifest.json`은 문서의 LF 정규화 SHA와 기존 자산의 원본 바이트 SHA를 구분한다. 커밋/CI·수정 권한 반납의 최종 상태는 본 작업 PR과 우리 상황판 종료 댓글에서 확인한다. 임시 서버는 검사 후 종료하며 실행 명령은 시연 절차에 남긴다.
