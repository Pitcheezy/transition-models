# Pitcheezy · 849843 영상 전용 전달팩

이 팩은 모니터 2에서 사용하는 공식 투구 클립 261개와 영상 전용 플레이어입니다.
전체 중계 영상이 아닙니다. 262구 중 849843:69:2는 자료 간 구종 불일치로 제외했습니다.
추천·실제 결과·미트 좌표는 표시하지 않습니다. 모니터 1의 Song 서비스가 보여 주는 이닝(초/말)·타자 이름·N구로 같은 공을 수동으로 맞춥니다.
두 모니터의 자동 동기화는 구현하지 않았습니다.

## 실행

압축을 새 폴더에 모두 풉니다. Python 3.10 이상이 필요합니다. 추가 패키지 설치는 없습니다.

- Windows: 이 폴더에서 터미널을 열고 `python -B verify.py`, 이어서 `python -B serve.py`
  - `python`이 Microsoft Store 안내만 띄우거나 "Python을 찾을 수 없습니다"라고 하면 `py -3 -B verify.py`, `py -3 -B serve.py`로 실행합니다.
- Mac: 이 폴더에서 터미널을 열고 `python3 -B verify.py`, 이어서 `python3 -B serve.py`
  - `python3`가 개발자 도구 설치 창을 띄우면 Command Line Tools 또는 python.org 설치 프로그램으로 Python을 먼저 설치합니다.
- 기본 주소는 `http://127.0.0.1:8741/`입니다. 터미널에 표시된 주소를 같은 컴퓨터 브라우저에서 엽니다. 8741이 사용 중이면 다른 포트로 열리며 터미널에 그 이유와 새 주소가 표시됩니다. `--port 숫자`로 지정할 수도 있습니다.
- 종료는 터미널에서 Ctrl+C입니다. 서버는 이 컴퓨터에서만 접근 가능합니다.
- 복구: 영상이 "serve.py 터미널이 켜져 있는지 확인" 메시지와 함께 멈추면 터미널이 닫혔는지 확인하고, 같은 폴더에서 serve.py를 다시 실행한 뒤 터미널에 표시된 주소로 페이지를 다시 엽니다. 같은 포트면 열려 있던 탭에서 "이 공 다시 불러오기"로 이어갈 수 있습니다.
- index.html을 직접 더블클릭하면 자료를 불러오지 못할 수 있습니다. 위 실행기를 사용하세요.

## 사용

모니터 1이 보여 주는 이닝(초/말)·타자 이름·N구(타석 내 투구 번호)로 같은 투구를 선택합니다.
타석 목록은 "9회 초 · Nico Hoerner"처럼, 전체 투구 목록은 경기 전체 순번과 함께 같은 정보를 보여 줍니다.
모니터 1의 "N번"은 타순이므로 타석 번호로 읽지 마세요. 화면의 투구 ID(849843:타석:구)는 보조 식별자입니다.
재생을 누른 뒤 이어보기를 켜면 다음 클립으로 넘어갑니다. 수동 선택은 이어보기를 멈춥니다.
누락·제외·파일 오류는 자동으로 건너뛰지 않고 멈춥니다. 확인 후 다음 공을 직접 선택하세요.
`?pitch=849843:1:2`처럼 특정 투구로 바로 열 수 있습니다. 등록되지 않은 ID면 첫 투구를 표시하고 상태줄에 알립니다. 영상 소리는 브라우저에서 조절합니다.
전체 화면 버튼은 투구 정보·영상·투구 ID를 함께 키우므로 재생 중인 공을 전체 화면에서도 확인할 수 있습니다.

## 파일

- registry.json: 투구 ID → 상대 파일 경로, SHA-256, 길이. 262행/261영상/1제외.
- clips/: 영상 261개. 원본 바이트를 그대로 복사했습니다.
- provenance/source-media.json: 기존 클립 연결 원문. 모델 추천 파일은 아닙니다.
- MANIFEST.json: 모든 전달 파일의 원본 바이트 해시(이 manifest 자체 제외).
- verify.py: 외부 접속 없이 실제 파일·크기·해시·전체 목록을 검사합니다. 실패하면 문제 파일 이름을 표시합니다. Finder의 .DS_Store, exFAT의 `._파일` 같은 OS 메타데이터는 경고만 하고 통과합니다.

비공개 전달용입니다. 공개 업로드·링크 공유는 이 팩 준비에 포함되지 않습니다.
출처: MLB 공식 투구 클립. SHA 일치는 바이트 식별이며 재배포 권리의 확인이 아닙니다.
전달 ZIP의 해시는 바깥에 있는 .receipt.json과 함께 대조하세요.
