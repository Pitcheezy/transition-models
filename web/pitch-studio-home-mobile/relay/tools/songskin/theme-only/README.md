# 색 테마만 얹는 판 (theme-only)

Song 고정 빌드 c47fe6cb의 화면 위에 Pitcheezy 색만 얹는 두 파일이다. Song이 2026-11-12 #38 댓글 6817925715에서 조건부로 동의했다(공동시험 통과 뒤 적용, 이 두 파일을 저장소에 올리고 SHA-256을 #38에 적기, 실제 폰 두 종에서 접근 코드를 켠 채 확인, 문제가 보이면 c47로 먼저 되돌리기). **아직 배포하지 않았다.** 3D 타자는 이번에 넣지 않는다.

| 파일 | 크기 | SHA-256 | 무엇 |
|---|---|---|---|
| `index.html` | 712 B | `b50993b505bfa78d5759c7c65706beca678f73ebfd084395fe3acaeb5d50048b` | Song의 index.html(659 B)에 색 CSS 링크 1줄을 더하고 theme-color 값을 `#f5f7f8`에서 `#091811`로 바꾼 것. 그 밖의 바이트는 Song 파일과 같다 |
| `pz/pz-theme.css` | 4640 B | `4badfb14d9661c46573dc63c701240cc4c8a92edb6a55f797ddf0e6274208fd3` | `../pz-theme.css`에서 3D 상자 규칙을 뺀 색 규칙. 크기·간격 속성은 없다 |

- 두 파일은 `.gitattributes`에서 줄바꿈 변환을 끄고 바이트 그대로 둔다.
- Song의 JS·CSS·favicon은 여기에 넣지 않는다. 배포 후보를 만들 때 Song 전달본을 바이트 그대로 쓴다.
- 확인한 것(2026-11-12, 노트북 로컬 서버, Chromium 375×812): 이 두 파일 그대로 첫 화면과 자세히 시트, 콘솔 오류 0, 가로 넘침 0, 스크립트는 Song 것 하나뿐. 실제 폰, 접근 코드 켠 상태, 안내 켜고 끄기, 나머지 시트와 262구 전체는 아직 확인하지 않았다.
- 배포 전에 필요한 것: 다른 모델 검토, 시험 주소 확인, Song에게 결과 공유, 사용자 승인.
