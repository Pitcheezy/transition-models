01 / FOLLOW THE PITCH

짧은 시연은 이 순서로

1

첫 타석을 이어 보기

첫 공을 열고 이어볼 범위를 ‘현재 타석’으로 고른 뒤 ‘관전 시작’을 누릅니다. 추천을 먼저 보고, 실제 위치와 종료 뒤 결과를 비교합니다.

2

원하는 공으로 이동하기

타석 아래 투구 순서를 누르거나 ‘선수·카운트로 공 찾기’에서 원하는 공을 고릅니다. 검색은 현재 경기 안의 투구 전 상황 기준입니다. 경기 선택바는 해당 공의 0초로, 영상 재생바는 현재 클립 안의 시각으로 이동합니다.

3

상세 기록과 근거 확인

관전 화면의 ‘상세 분석’에서 같은 공의 수치를 확인합니다. 첫 타석 3구 상세 분석과 모델 근거를 통해 추천 비중과 사건확률, 예측 평가와 추천 효과를 구분합니다.

02 / READ THE NUMBERS

숫자의 뜻부터 정확하게

구종 선택 비중
제공받은 추천 후보의 비중입니다. ‘스트라이크가 될 확률’이나 ‘타자를 잡을 확률’이 아닙니다. 상위 후보만 보여주면 합이 100%보다 작을 수 있습니다.
추천의 위치
현재 저장 데모에서는 과거 실제 투구 분포를 요약한 근사 위치입니다. 반드시 던져야 할 최적 지점이나 포수가 실제 요구한 위치로 읽지 않습니다.
실제 공의 위치
경기 기록의 홈플레이트 통과 위치이며 포구 지점이 아닙니다. 가로 좌표와 지면 기준 높이를 ft로 표시합니다. 영상 속 픽셀 위치와 그대로 빼서 오차를 계산하지 않습니다.
참고 존과 기록 존
점선 참고 존은 높이 1.5~3.5ft의 고정 예시이며 타자별 실제 존이 아닙니다. 실제 위치 공개 뒤 보이는 기록 존은 같은 투구의 Statcast 상·하단 높이와 홈플레이트 폭 17인치를 사용합니다. 심판 판정을 계산하는 경계는 아닙니다.
제공되지 않는 값
현재 전체 경기 자료에는 볼·스트라이크·안타 등의 사건확률과 선택의 기대가치가 없습니다. 구종 비중이나 예시 숫자로 대신하지 않습니다.
투수의 앞선 선택
지금 보는 공보다 앞서 같은 투수가 이 경기에서 던진 공만 집계합니다. 구종별 빈도와 기록이 있는 공의 평균 구속을 보여주며, 현재 공·이후 공·다른 투수·시즌 기록은 포함하지 않습니다.
03 / KNOW THE MODE

저장 경기와
실시간 관전

컵스 대 파드리스 경기는 현지 2026년 9월 29일, 한국 9월 30일 경기입니다. 71타석·262구 중 추천은 246구, 미지원은 16구입니다. 연결한 공식 영상은 261개의 개별 투구 클립이며 연속 중계 영상 파일은 없습니다. 구종 기록이 다른 1구는 영상을 제외했습니다.

관전 화면의 첫 3구는 AI가 프레임으로 확인한 공 도착·접촉 구간의 상한부터 실제 위치를 표시합니다. 나머지 클립은 종료 뒤 위치를 표시합니다. 실제 구종·판정·타구 결과는 모든 투구에서 클립 종료 뒤 공개합니다. 정확한 단일 포구 프레임이나 전 경기의 정밀 동기화를 검증한 것은 아닙니다.

경기 투구 선택바는 시간축이 아니라 262구의 순서입니다. 놓으면 고른 투구의 시작으로 이동하고, 현재 클립의 시간 탐색은 별도 영상 재생바를 사용합니다. 이어보기는 클립 종료 뒤 결과를 5초간 보여주고 다음 공으로 넘어가며, 영상이 없거나 오류가 나면 멈춥니다.

경기 후 저장 자료이며 당시 실시간 예측을 입증하지 않습니다. 첫 3구 외 영상은 MLB 서버 연결이 필요합니다. 영상이 열리지 않으면 ‘상세 분석’에서 같은 공의 결과를 직접 공개할 수 있습니다.

실시간 관전은 별도로 준비합니다

최신 경기 정보를 받아 추천이 갱신되는 화면에서는 갱신 시각과 연결 상태를 함께 보여줘야 합니다. 연결이 끊겼거나 자료가 없을 때 과거 추천을 새 추천처럼 표시하지 않습니다.

모든 MLB 경기·선수를 지원한다고 아직 안내하지 않습니다.

04 / MODEL EVIDENCE

모델은 무엇을 확인했나요?

결과 예측 모델은 상황과 후보 공에 따른 결과 확률을 계산하고, 추천 정책은 그 결과를 바탕으로 선택지를 비교합니다. 예측이 좋아졌다는 것과 추천을 따르면 실제로 더 유리하다는 것은 별도로 평가합니다.

현재 저장 경기 화면에는 저장된 추천 후보·선택 비중·근사 위치가 연결돼 있습니다. 모델 내부의 사건확률이나 선택별 기대가치는 이 자료에 포함되지 않아 표시하지 않습니다.

예측 비교 · NLL 0.0137 감소
2025년 개발 자료 311,721구에서 G0 모델을 단순 빈도 기준선과 비교했습니다. NLL은 실제로 일어난 결과에 얼마나 높은 확률을 주었는지 평가하는 점수이며, 낮을수록 좋습니다. 정확도가 몇 %라는 뜻이나 새 경기의 성능 보장은 아닙니다. 확률 보정 지표에서는 기준선이 더 좋았습니다. 고정 평가 보고서

운영 기록 · 263구 수집, 지원 185구 중 180구 추천
월드시리즈 1차전의 비공개 자동 수집·기록에 관한 공급자 보고입니다. 전체 263구 중 지원 투수의 공은 185구였고, 그중 180구에 추천이 기록됐습니다. 공개 업로드는 꺼져 있었으며 공개 관람자는 0명이었습니다. 이 사이트가 그 경기를 공개 서비스했다는 뜻은 아닙니다. 운영 보고 · 추천 분모 확인

영상 분석은
근거가 있을 때 더합니다.

관전 화면의 ‘미트 가로 관측’을 켜면 클립 종료 뒤 받은 셋업 추정의 가로값을 별도 축에서 볼 수 있습니다. 자료가 없거나 판독을 기권한 공은 그 상태를 표시합니다. 현재 영상 프레임과의 대응·높이·투수 의도는 검증되지 않았으므로 존 위에 점을 겹치거나 제구 오차를 계산하지 않습니다.

받은 경기 자료의 셋업 추정과 별도 CV 관측은 출처가 다른 기록입니다. 근거 이미지는 투구 ID와 출처를 대조한 뒤 추가합니다.

미트 위치와 투수 의도는 다릅니다

미트 관측이 곧 투수의 목표를 뜻하지는 않습니다. CV가 없는 경기에서도 추천과 실제 결과를 비교할 수 있습니다. 별도 CV 연구 화면의 39구 관측과 2경기·86장 평가는 현재 경기 전체나 추천 모델의 정확도를 검증한 결과가 아닙니다.
